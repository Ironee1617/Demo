# 공중 전투와 전체 캐릭터 리깅 개선

2026-10-20. 25층 등반·동료 영입·증강 선택의 기본 구조를 유지합니다. 실행 파일은 `Build/TowerSkyRig/TowerSkyRig.exe`이며 공유할 때는 폴더 전체가 필요합니다.

## 추가·변경

- 비행 몬스터는 이동 방식만 다릅니다. 주인공과 모든 동료의 공격·스킬이 실제 사거리와 충돌 범위에 닿으면 피해를 줍니다. 2층부터 파티 구성과 관계없이 한 마리씩 출현하며, 동료를 해고해도 비행을 유지합니다.
- 16개 지형의 기존 상단 발판에서 높이 2.4 / 3.8 / 5.2로 이어지는 세 단을 추가했습니다. 각 단은 일반 점프로 올라갈 수 있습니다. 비행 몬스터는 이 발판 위에서 움직이고, 동료는 필요한 높이까지 경로를 따라 올라갑니다.
- 최고 발판에 맞춰 카메라 추적 범위, 배경, 날씨와 투사체 상한도 확장했습니다.
- 플레이어는 기존 가중치 메시와 뼈대를 유지하면서 이동 시작·정지·점프·착지·대시를 0.12초 동안 연결합니다. 회전은 짧은 각도 방향으로 보간하고, 점프 꼭대기·피격·착지 자세도 부드럽게 전환합니다.
- 신화 동료 50명은 기존 관절·부위별 모델을 유지합니다. 방향을 바꿀 때 보행 위상을 초기화하지 않고, 가속도에 따른 기울기와 공중 자세를 부드럽게 연결합니다. 다리를 뻗은 상태에서 감속할 때 골반이 갑자기 올라오던 동작을 수정했습니다.
- 일반 몬스터 42종과 보스 7종에 각각 14개 관절을 연결했습니다. 원본 그림을 유지하는 가중치 메시로 머리·몸통·사지·날개·옷자락 등을 움직입니다. 이족·로브·사족·기어다니기·슬라임·날개·촉수·영체의 체형별 동작을 사용합니다.
- 플레이어·동료·일반 적·보스의 보행에는 실제 이동 속도를 전달합니다.

## 제거

- 공중 적의 원거리 직업 전용 피격 판정과 안내 문구.
- 원거리 동료가 없으면 공중 적이 나오지 않던 조건과 마지막 원거리 동료 해고 시 강제 착지.
- 몬스터 한 장 전체를 늘이고 기울이거나 보스를 통째로 회전시키던 애니메이션 코드.
- 플레이어 루트 위치를 매 프레임 별도로 반올림하던 처리와 이동 전환 시 즉시 자세 교체.

## 재현과 검증

`Tests/Build-TowerDemo.ps1`은 `.validation/TowerDemoProject`에 독립 파일 복사본을 만들어 빌드합니다. 원본 Assets·Packages를 연결하거나 공유하지 않습니다.

- `Tests/Run-TowerPlatformTests.ps1`: 16개 지형의 일반 점프 도달성.
- `Tests/Run-TowerEditorSmoke.ps1`: 실제 전투·발판 점프/낙하·동료 합류·보스와 기존 반격 기능.
- `Tests/Run-TowerThemeSmoke.ps1`: 실제 리깅 렌더러, 원본 텍스처/UV와 7개 테마.
- `Tests/Run-TowerAnimationSmoke.ps1`: 동료 50명의 20,700개 자세, 원본 리그 16개와 동료 50명의 9가지 상태 전환, 실제 발 접촉·얼굴·무기 보존.
- `Tests/Run-TowerMonsterRigSmoke.ps1`: 몬스터 49종의 관절·가중치, 움직임 연속성, 메시 뒤집힘·늘어짐, 30/60/120Hz 동작 일관성과 갤러리.

수정 전후의 보고서와 화면은 `Artifacts/TowerRig/`에 저장합니다. 수치 검사는 형태와 연속성의 회귀를 찾는 기준이며, 최종 동작은 캡처 화면과 함께 확인합니다.

## 검증 결과

- 순수 규칙 모델: 발판 5개·테마 8개·난이도 6개·진행/신화 30개, 총 49개 통과.
- 발판 실행: 16개 지형·7개 테마에서 점프 284회·낙하 284회, 최고 발판 카메라 검사 38회 통과. 개별 경로의 출발점은 검증용으로 배치하고 실제 입력으로 이동합니다. 전체 층을 한 번에 등반했다는 의미는 아닙니다.
- 공중 전투: 주인공 근접·투사체 피해, 전 직업 대상 선택, 근접 동료의 지상→최고 발판 추적, 단독 플레이 출현과 해고 후 비행 유지 통과.
- 인물 리깅: 66개 리그 × 9개 상태 전환 통과. 최대 한 프레임 전환 변위는 몸 높이의 1.865배에서 0.170배로 감소했습니다. 동료 50명의 20,700개 자세에서 기존 발 접촉·얼굴·복장·무기 보존 검사를 유지했습니다.
- 몬스터 리깅: 49종·각 14개 관절, 실제 가중치가 있는 관절은 체형별 6~14개입니다. 16,226개 자세에서 뒤집힘 없이 통과했고, 최대 프레임 변위는 몸 높이의 0.0295배, 30/60/120Hz 간 최대 자세 차이는 0.0021배입니다.
- 동료 실행: 기본 공격 50종·전용 스킬 200종 및 진형/이동 회귀를 포함한 266개 사례 통과. 보스층 실제 입력 전투와 기존 회피 반격·보상 검증도 통과했습니다.
- 테마 표시: 7개 테마·49종 외형, 게임과 도감의 실제 리그 112개 검사 통과.

애니메이션 비교 자료는 `Artifacts/TowerRig/Final/`에, 몬스터 최종 캡처는 `Artifacts/TowerRig/MonstersVerified/`에 있습니다. 검증 종료 후 Unity 편집기는 원래 씬을 수정하지 않은 정지 상태로 복원했습니다.
