# 잠수부 · 밧줄 작살

`D:\수족관술래잡기\모델링파일\잠수부`와 `잠수부 무기`의 OBJ 및 PBR 텍스처를 사용합니다. 원본 파일은 그대로 보관합니다.

- 잠수부: 24,532 삼각형, 15본 리깅. 총을 잡은 대기 자세와 오리발을 차는 수영 동작을 전환합니다.
- 작살총: 23,993 삼각형. 분리한 발사체는 2,199 삼각형입니다. 원본 총 옆에 떨어져 있던 흰 판 형태의 재구성 잔여물은 제거했습니다.
- 얼룩진 원본 텍스처를 부위별 재질과 새 2K UV 페인트/표면 속성 맵으로 교체했습니다. 잠수부는 헬멧·마스크·슈트·장갑·오리발·산소통 등의 13개 슬롯, 작살총은 총몸·손잡이·방아쇠·금속 촉 등의 7개 슬롯을 사용합니다. 새 색 경계는 UV 공간에 베이킹해 삼각형 모서리 모양으로 갈라지지 않습니다.
- 검지는 방아쇠에 걸치고 중지·약지·소지는 손잡이를 감싸며 엄지는 반대편을 받치도록 오른손을 다시 모델링했습니다. 1인칭은 손목부터 팔꿈치까지 이어지는 전용 소매를 사용해 잘린 몸통 조각이 보이지 않습니다.
- 술래의 1인칭 및 술래 관전 시 화면 오른쪽 아래에 손과 작살총을 표시합니다. 발사 반동, 수영 중 작은 흔들림, 회수 중 총을 내리는 동작을 적용합니다.
- 발사체는 최대 0.75초 동안 초속 20m로 이동합니다. 물고기/외계인/알/지형에 처음 맞거나 사거리에 도달하면 돌아옵니다. 회수 중 추가 피해는 없습니다.
- 밧줄은 총구의 고정점과 작살 뒤끝을 연결합니다. 발사 후 **3초 쿨타임**이 끝나는 순간 회수가 완료되고 장전된 작살이 다시 표시됩니다. 회수 경로는 이동하는 술래 위치를 따라갑니다.
- 발사/명중/회수 시점과 위치는 호스트가 결정하고 기존 스냅샷으로 전송합니다. 모든 플레이어가 같은 발사체 상태를 봅니다.

## 구성

`Assets/Demos/HideAndSeek/Equipment`에 모델·재질·프리팹·애니메이션과 가져오기/검증 도구가 있습니다. Unity 런타임은 `.blend` 또는 Blender 설치 없이 실행됩니다. 기존 물고기/외계인 리깅과 포식 로직은 사용하던 자산을 유지합니다.

1인칭 장비는 예약 레이어 **30**과 깊이만 초기화하는 보조 카메라를 사용합니다. 월드 카메라와 동일한 FOV/화면 비율을 사용해 밧줄과 총구가 맞닿습니다. 레이어 30에는 월드 오브젝트를 배치하지 않습니다. 관전자/외계인/결과 화면에서는 해당 조건에 맞춰 장비를 숨깁니다.

`AQUARIUM_EQUIPMENT_SOURCE`를 내보내기 폴더로 지정하고 `Aquarium/Equipment/Import diver and harpoon` 메뉴를 실행하면 재생성할 수 있습니다. `AquariumEquipmentChecks.ImportAndCheck`는 가져오기 후 리깅·애니메이션·1인칭 화면·직렬화된 발사/회수 흐름을 검증합니다. `CheckAndBuild`는 검증과 Windows 빌드를 실행합니다.

`Tests/Run-ModelTests.ps1`은 명중 후 회수, 이동하는 소유자 추적, 회수 중 재피해 방지, 빗나간 작살의 회수, 기존 쿨타임을 검사합니다. 개발 빌드의 `-aqTest harpoon -aqDuration 10 -aqReport <json> -aqCapture <png>`는 실제 게임 루프에서 여러 번 발사하고 무기·밧줄·회수 상태를 기록합니다.

밧줄은 물속에서 느슨하게 흔들리는 시각 효과이며, 지형에 감기는 로프 물리 시뮬레이션은 적용하지 않았습니다.
