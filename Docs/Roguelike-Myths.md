# 신화 동료 콘텐츠

2026-10-22 100층 개편부터 신화 구매와 선택은 없습니다. 출발 직후, 30층, 60층의 동료 영입에서 10개 신화 50명 전체가 후보로 나오며, 같은 신화 동료 2·3명을 모으면 신화 시너지가 발동합니다([시너지 표](Roguelike-Demo.md#100층-개편)). 한 층을 클리어할 때마다 얻는 영구 포인트 1점은 상점 층에서 씁니다. 같은 층의 보상이나 저장을 반복해도 포인트를 중복 지급하지 않습니다.

각 동료는 기본 공격과 고유한 기본 공격력·속도·사거리·치유량으로 시작합니다. 능동 스킬 네 개와 누적 특성 세 개는 층 클리어 증강으로 따로 습득합니다. 스킬은 세 단계까지 강화하고, 특성은 소유한 동료에게만 누적 적용됩니다. 파티는 세 명까지 편성합니다.

명단은 게임용으로 선정한 신과 영웅이며, 인간형 도트 캐릭터로 재해석합니다. 12간지는 우선 자·축·인·묘·진 다섯 수호자를 제공합니다. 각 신화의 영입 등급은 명단 순으로 실버·실버·골드·골드·다이아입니다.
