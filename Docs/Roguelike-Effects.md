# 로그라이크 고해상도 전투 효과

서약의 탑의 모든 스킬·공격·투사체·충돌·잔상 이펙트는 `TowerVfx.cs`가 실행 중에 생성하는 고해상도 광원 스프라이트로 그립니다. 캐릭터와 몬스터의 원본 도트 이미지는 그대로 두고, 이펙트만 실사풍 빛·연기·파편으로 표현합니다. 외부 이미지 생성 서비스는 사용하지 않았으며, 모든 텍스처는 코드의 거리장·노이즈 수식으로 만들어 런타임 메모리에만 존재합니다.

## 렌더링 기반

- **해상도.** 모든 효과 텍스처는 128 PPU로 생성하고 Trilinear 필터와 밉맵을 적용합니다. 32 PPU 도트 캐릭터보다 4배 조밀하며, 1600×900에서 2배 슈퍼샘플링, 1440p 이상에서는 화면 픽셀과 1:1로 표시됩니다. 효과는 픽셀 격자에 스냅하지 않고 연속 좌표로 움직입니다.
- **가산 발광.** `Resources/Tower/Effects/TowerEffectAdditive.shader`(`PrototypeLab/Tower/EffectAdditive`)는 정점 색과 `_Color`를 곱한 뒤 알파를 RGB에 곱해 `One One`으로 더합니다. 빛·불꽃·번개·스파크·검기·룬은 이 머티리얼로 겹쳐 그려 블룸처럼 밝아집니다. 연기·먼지·파편·화살·포탑처럼 어두운 요소는 `Sprites/Default` 알파 블렌딩을 사용합니다.
- **절차 텍스처.** 부드러운 광원(256²), 고온 핵(128²), 충격 고리(256²), 광선 줄기(256×64), 스파크(128×32), 연기 4종(160², fBm 노이즈), 불꽃 시트 8프레임(128×192, 순환 노이즈 이류), 검기 시트 6프레임(256², 극좌표 초승달 스윕과 모션 블러), 얼음 결정(96²), 마법진(512², 이중 고리·육망성·눈금·룬 띠), 화살(256×64, 강철 촉·목재 자루·깃), 비전 탄두(192×64), 육각 방패 격자(256²), 운석(128², 분화구와 진행 방향 가열면), 파편 3종(64²), 포탑 시트 8프레임(160×128, 반동·총구 화염·광학 렌즈).
- **클립 모델.** 각 요소는 수명·속도·항력·중력·회전·속도 정렬·이징 스케일·색 그라디언트·페이드 인/아웃·플리커·펄스를 가집니다. 음수 나이로 지연 재생을 표현하고, 방출기(불씨·연기·반짝임·서리·독무·치유 입자·광 궤적)가 투사체와 영역을 따라 입자를 계속 생성합니다. 완료된 스프라이트 오브젝트는 풀(최대 512)로 재사용합니다.

## 원본 파일

`Resources/Tower/Effects`의 `slash_0..6.png`, `swirl.png`, `arrow.png`는 `RPGAsset` 원본의 바이트 동일 복사본으로 유지합니다(`Tests/Run-TowerSmoke.ps1 -ArtOnly`가 SHA-256 일치를 확인). 고해상도 이펙트는 이 48픽셀 원본 대신 자체 검기·화살 텍스처를 그리므로 런타임에는 더 이상 참조하지 않습니다.

## 런타임 연결

`TowerVfx.Create(parent)`가 서비스를 만들며 첫 생성 시 모든 텍스처를 준비합니다. `Tick(dt)`만 시간을 진행하므로 게임의 일시정지·히트스톱과 동기화됩니다. `Projectile()`는 같은 투사체 루트에 다시 호출하면 기존 레이어를 교체하고, `HostileProjectile()`·`AttachZone()`은 게임이 소유한 루트에 시각 레이어만 붙입니다. 루트가 삭제되면 다음 `Tick()`에서 레이어가 정리되고, `Clear()`는 서비스가 만든 시각 효과만 제거합니다. 난수는 서비스 전용 `System.Random`을 사용하므로 전투의 치명타 난수에 영향을 주지 않습니다.

## 검증

`TowerArtSmokeDriver`의 VFX 갤러리는 16개 효과의 시전 표시, 프레임 변화, 충돌 표시, 10초 후 소멸을 검사하며, 효과 아래의 모든 렌더러가 Point 필터가 아닌 64픽셀 이상 텍스처를 사용하는지 확인합니다(`HighResolution`). 캐릭터 도트는 계속 Point 필터를 요구합니다. 회피 잔상 검사는 가중치 메시 복제가 원본 포즈를 고정하는지와 0.25초 뒤 만료되는지를 그대로 검사합니다. 2026-10-22 에디터 플레이 세션에서 갤러리 단계(`visibleEffects=16`, `animatedEffects=16`, `effectsExpired=true`)를 통과했습니다.
