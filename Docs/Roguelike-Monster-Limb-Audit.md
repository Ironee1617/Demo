# 몬스터 사지·공격 모션 개별 점검

대상은 테마 일반 몬스터 42종, 보스 7종, 기존 몬스터 5종이다. 원본 PNG 및 기존 `.meta`는 변경하지 않았다.

## 기준과 변경

이전 통과판의 세 C# 소스와 결과를 `.validation/MonsterLimbAuditBaseline/`에 독립 복사했다. 이전 결과는 49종, 16,226프레임 통과였으며, 원본 비교 캡처는 `Artifacts/TowerRig/MonstersVerified/`에 남아 있다.

개별 실루엣과 기존 캡처를 다시 대조한 결과, 기존에는 관절이 있어도 공격이 공통 팔 흔들기 위주였다. 이번에는 각 종에 공격 유형을 지정하고 준비·타격·복귀에서 움직이는 관절을 구분했다. 붉은 슬라임의 이족 분류를 고쳤고, 기존 해골 가면 주술사의 깃 장식을 날개로 취급하던 분류도 로브·시전 동작으로 바로잡았다. 스태프·창·검·활은 손에 붙은 강체 영역을 유지한다.

이 리그는 한 방향으로 그려진 원본 위의 2D 가중치 메시다. 14개 이름 있는 계층 관절을 사용하지만, 실제 가중치가 있는 관절은 보이는 체형에 따라 다르다. 슬라임의 측면 관절은 몸체 질량을 표현하며 손으로 취급하지 않는다. 로브에 가려진 발, 겹쳐 가려진 동물의 다리, 문어의 보이지 않는 촉수를 새로 그렸다고 주장하지 않는다. 기존의 연결된 메시와 원본 실루엣을 유지하면서 보이는 말단과 몸통의 상대 움직임을 검사한다.

## 실행 검증 방법

- 기존 49종 상태 검사에 legacy 5종을 포함해 이동·공격·시전·피격·사망과 보스 패턴의 연속성 및 삼각형 뒤집힘을 검사한다.
- 공격은 같은 시각의 대기 모션을 별도 리그로 실행하여 비교한다. 전체 위치 이동을 뺀 국부 메시 변형과 머리·사지·말단 관절의 실제 각도 변화가 있어야 통과한다.
- 준비와 타격에 각각 0.75도 이상의 관절 변화, 두 개 이상의 실제 변화 관절, 복귀 시 키의 2.5% 미만 잔차를 요구한다.
- 각 테마의 모든 7종과 legacy 5종을 한 행씩 배치한 준비/타격/복귀 갤러리 8장을 출력한다. 열 순서는 준비·타격·복귀, 행 순서는 위 표의 해당 테마 순서다.
- `attackAudits`에는 각 개체 이름·공격 유형·변화 관절·최대 각도·국부 변형·복귀 오차가 기록된다. `attackSheets`에 개별 검토 갤러리 경로가 기록된다.
