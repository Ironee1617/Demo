# 로그라이크의 7개 맵 테마

새 등반의 1층 테마는 7개 중 무작위로 정합니다. 같은 테마가 5개 층 동안 유지되고, 5→6층·10→11층·15→16층·20→21층에서 직전 테마를 제외한 6개 중 하나를 다시 뽑습니다. 두 구간 이상 지난 테마는 다시 등장할 수 있습니다. 25층 데모 한 판에서 사용하는 테마 구간은 총 5개입니다.

테마마다 일반 몬스터 6종과 보스 1종을 제작했습니다. 전체 구성은 일반 42종·보스 7종이며, 새로 제작한 테마별 픽셀 아틀라스 7장을 사용합니다. 종마다 다른 실루엣과 재질, 세부 명암을 적용했습니다. 테마가 바뀌면 배경·지면·발판·장식·입자 효과와 몬스터 외형·이름·능력치·공격 색상이 함께 바뀝니다. 테마 선정은 보상 추첨과 별도 난수 흐름을 사용하므로 증강 새로고침이나 선택으로 다음 테마를 바꿀 수 없습니다.

모든 테마는 연속된 지면 위에 **16종의 발판 패턴** 중 하나를 층마다 무작위로 배치합니다. 패턴마다 발판은 **9~12개**, 전체 설계에는 **170개**가 있습니다. 16개를 한 묶음으로 섞어 모두 한 번씩 사용한 뒤 다시 섞으며, 묶음 경계에서도 직전 층과 같은 패턴이 연속으로 나오지 않습니다. 배치는 시작 시드와 층 번호만으로 정하므로 보상 추첨이나 장식 난수 소비에 영향을 받지 않습니다. 테마가 유지되는 5개 층 안에서도 발판 패턴은 바뀝니다.

지면의 높이는 `-3`, 발판 상단은 `-1.8 / -0.4 / 1.0`입니다. 첫 단차는 `1.2`, 이후 단차는 `1.4`이며, 기본 이동 속도 `6`과 일반 점프로 모든 발판에 오를 수 있도록 연결했습니다. 폭 `2.6~4.8`의 착지 공간과 낮은 진입 발판을 여러 곳에 두어 위아래로 이동하며 탄막을 피할 수 있습니다. 시작 위치 `x=-12`와 출구 `x=26`의 공간도 비워 둡니다. 발판 위에서 **S 또는 ↓를 짧게 누르면** 현재 발판 아래로 내려가며, 그 아래 발판에는 다시 착지할 수 있습니다.

7개 테마 모두 발판의 실제 착지 높이에 상단선을 맞추고, 끝부분 타일을 발판 폭에 맞게 잘라 그립니다. 용암은 현무암과 불씨 이음매, 암석은 석재 받침, 정글은 뿌리와 덩굴, 빙결은 고드름, 수상은 말뚝과 결속부, 구름은 구름 받침과 금빛 장식, 폐허는 석조 받침으로 아랫면도 다듬었습니다. 수상지대와 구름지대도 통과 가능한 길을 유지하며, 현재 배경에는 별도의 낙사·용암 피해·미끄러짐 판정을 추가하지 않았습니다.

일반 몬스터는 근접형·원거리형·중량형을 두 종씩 섞고, 각 종에 서로 다른 체력·공격력·이동 속도·공격 주기 배율을 적용합니다. 2층부터 파티와 관계없이 해당 테마의 공중 개체 한 마리를 추가합니다. 비행 여부는 공격 자격을 제한하지 않으며, 근접 공격도 실제로 닿으면 피해를 줍니다. 공중 개체는 새로 추가한 상단 세 단 발판 위에 머무르고, 동료 해고와 관계없이 비행을 유지합니다.

일반 지상 개체 수는 기존의 `4 + (층 - 1) / 3`을 유지합니다. 따라서 한 층의 출현 개체 수와 테마 전체의 몬스터 종류 수는 다릅니다. 층마다 여섯 종의 순서를 섞어 배치하며, 지상 적이 6마리 이상인 층에는 여섯 종이 모두 등장합니다.

보스는 **5·10·15·20·25층**에 현재 테마의 보스 한 마리가 등장합니다. 모든 보스는 지상 판정을 사용해 모든 직업이 공격할 수 있습니다. 기본 체력은 5층 420, 10층 577.5, 15층 735, 20층 892.5, 25층 1050이며 테마별 체력 배율을 추가 적용합니다. 보스별 외형·전투 배율·탄막 색상을 사용하며 연속 조준 사격·쌍나선 탄막·도약 강타의 공통 전투 패턴을 공유합니다.

구성과 이름은 `Assets/Demos/Roguelike/Scripts/TowerThemeCatalog.cs`, 선정과 유지 규칙은 `TowerRun.cs`, 지도 표현은 `TowerWorld.cs`에서 관리합니다. `Tests/Run-TowerThemeTests.ps1`은 1,000층 동안의 경계 전환, 직전 테마 제외, 모든 후보의 도달 가능성, 보상 난수 분리와 49종 구성을 검증합니다. `Tests/Run-TowerDifficultyTests.ps1`은 5층 주기 보스와 성장 수치를 검증합니다.

발판 설계와 층별 선정은 `TowerPlatformCatalog.cs`에서 관리합니다. 이번 발판 수정의 `Tests/Run-TowerPlatformTests.ps1` 모델 검증은 **5개 모두 통과**했습니다. 16종의 구분·착지 폭·입구와 출구 여유 공간, 기본 이동과 점프로 모든 발판에 도달하는 실제 중력 궤적(`dt=0.04` 및 60fps), 16층 묶음의 전체 패턴 사용과 연속 중복 방지, 시작 시드와 층 번호만으로 결정되는 배치를 확인합니다.

테마 검증은 `Tests/Run-TowerThemeSmoke.ps1`로 7개 맵·49개 서로 다른 외형·42개 실제 프레임과 5→6층 전환을 확인합니다. 공중 개체 수는 파티와 관계없이 1층 0마리, 2층부터 1마리로 검사합니다. 보스 실행 검증은 25개 층의 능력치·5층 주기 보스·공격 준비 시간·탄막·실제 입력 전투·처치 후 보상 1회를 확인합니다.

최신 테마·몬스터 리깅과 상단 발판 적용 실행 파일은 `Build/TowerSkyRig/TowerSkyRig.exe`입니다. 공유할 때는 `TowerSkyRig` 폴더 전체를 전달합니다. Unity에서는 기존 `20_Roguelike.unity` 씬을 사용합니다.


발판 런타임 검증: 16개 배치의 170개 발판을 실제 이동·점프 입력으로 각각 오르고, 한 프레임의 하강 입력 후 낮은 면에 착지하는 동작 170회를 확인했습니다. 이 중 40회는 다른 발판으로 내려왔습니다. 각 배치에서 지상 탄환 피격과 위 발판에서의 회피를 비교한 16쌍, 7개 테마 화면, 동료 이동·일반 전투·보스 전투 검증이 모두 통과했습니다. 각 이동 검사는 출발 발판에 배치한 뒤 정상 입력으로 수행하며, 한 번의 연속 완주를 뜻하지 않습니다.

최종 Windows 실행 파일에서도 실제 전투·보상 선택·스킬·25층 완주 자동 플레이와 화면 6장을 확인했으며 오류 없이 종료했습니다.

## 배경과 몬스터 아트 개편 (2026-10-20)

기본 제공 imagegen 도구로 1536×1024 아트 보드 7장을 제작했습니다. 각 보드에는 전용 원경 1개와 일반 몬스터 6종·보스 1종이 들어 있습니다. 용암 성채, 수정 동굴, 정글 신전, 빙하 성소, 수몰 유적, 구름 궁전, 잊힌 사원으로 환경을 구분했습니다. 색면의 깊이와 재질을 분리하고, 실제 전투 화면에서는 원경 밝기를 낮춰 캐릭터와 착지면이 잘 보이게 했습니다.

실제 이미지 경계는 `Assets/Demos/Roguelike/Resources/Tower/Themes/AtlasLayout.json`에 기록합니다. 몬스터는 독립된 투명 실루엣으로 잘라 읽고, 이웃 조각을 분리합니다. 원본 PNG와 본체 픽셀의 색상·투명도는 보존합니다. Point 필터·무압축·밉맵 없음 설정을 사용하며 기존 공격 동작과 지면 맞춤을 유지합니다. 발판과 지면은 7종의 48ppu 재질로 다시 그렸고, 발판 상면·너비와 16개 랜덤 배치의 물리 좌표는 그대로 사용합니다.
