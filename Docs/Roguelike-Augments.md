# 서약의 탑 · 영웅과 증강 도감

플레이어 1명 + 신화 10개·동료 50명. 동료별 스킬 4종·특성 3종과 플레이어 스킬 8종·특성 15종으로, 스킬 208종·특성 165종의 총 373종 증강이 있습니다. 동료 영입 카드는 별도입니다.

한 층 클리어마다 영구 포인트 1점을 받습니다. 기본 해금된 에덴의 천사 또는 5포인트로 구매한 다른 신화를 메인 화면에서 선택한 후 출발합니다. 한 런에는 선택한 신화의 동료 다섯 명만 영입 후보로 등장합니다. 포인트·구매·선택·층별 지급 내역은 저장되며 같은 층은 중복 지급하지 않습니다. 전체 명단과 기본 가격은 [신화 동료 콘텐츠](Roguelike-Myths.md)를 참고하세요.

매 층 클리어 후 영입(파티 3명 중 빈자리 있을 때), 보유 영웅의 스킬·특성을 함께 추첨합니다. 각 카드 등급은 실버 40%·골드 40%·다이아 20%입니다. 같은 영웅의 서로 다른 카드 세 장이 함께 나올 수 있습니다. 각 카드는 해당 층에서 한 번씩 재추첨할 수 있습니다.

스킬은 증강으로 습득한 후 자동 사용합니다. 같은 스킬을 다시 고르면 최대 Lv.3까지 강화되며, 레벨마다 위력 +35%·범위 +10%·쿨타임 -15%가 기본 수치에 가산됩니다. 지속 시간이 있는 스킬은 단계마다 지속 시간 +20%가 적용됩니다. 특성은 반복 선택해 소유한 영웅에게 누적합니다. 실제 적용 수치와 남은 쿨타임은 영웅·동료 관리 화면에서 확인할 수 있습니다.

아래 수치는 특성 없는 Lv.1 기준입니다. 지속 공격의 피해는 1회 타격/발사당 값입니다. 검무는 표시된 수량만큼 반복 타격하고, 독 구름은 0.7초마다, 소환진은 0.85초마다 발사합니다. 생명력 흡수 스킬은 가한 피해의 35%를 회복합니다. 보호막은 최대 체력의 65%까지 중첩됩니다. 방어력은 피해에 100/(100+방어력)을 곱해 적용합니다. 동료는 쓰러지지 않고 플레이어를 지원하며, 치유·보호막은 플레이어에게 적용됩니다. 각 신화의 스킬 이름과 조합은 다르며, 전투 효과 16종을 공유합니다.
