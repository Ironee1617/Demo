# Coral Gallery 1.8 수족관 맵

사용자가 제공한 상단 배치 이미지의 구불구불한 수조·산책로 윤곽을 유지한 수심 12 m 수족관입니다. 두 번째 수중 사진의 각진 절벽, 앞으로 돌출된 암반과 깊게 파인 하부를 기준으로 암석 구조를 다시 모델링했습니다. 배경 전용 씬에는 사람 모델이 없으며, 기존 게임 캐릭터는 그대로 사용합니다.

## 실행·편집

- 게임 씬: `Assets/Demos/HideAndSeek/30_HideAndSeek.unity`
- 배경 편집 씬: `Assets/Demos/HideAndSeek/31_CoralGallery.unity`

- 실제 Unity 렌더링·검사 기록: `Artifacts/CoralGallery/`

## 1.8 변경 내용

암반을 구성하는 삼각형의 방향을 수정했습니다. 기존에는 날카로운 절리·겹침 부위에서 평균 표면 방향으로 삼각형을 뒤집어, 카메라 각도에 따라 일부 면이 사라졌습니다. 이제 실제 표면을 추출하는 각 사면체의 안쪽·바깥쪽을 기준으로 방향을 정합니다. 아주 짧은 모서리가 한 점으로 붕괴하지 않도록 교차점도 보정했습니다. 암반의 실루엣과 충돌 필드는 유지합니다.

7개 암반 전체에 대해 **열린 모서리 0, 뒤집힌 공유 모서리 0, 비정상 연결 0, 붕괴 삼각형 0**을 검사합니다. 모래도 경계가 하나의 닫힌 윤곽으로 이어지며 내부 구멍이 없는지 확인합니다. 도보 테두리·돌출 띠의 밑면과 원기둥 끝면도 채웠습니다.

산호와 해조류는 색상뿐 아니라 입체 구조를 다르게 만들었습니다.

- 산호 6종 형태: 사슴뿔 가지, 층층이 말린 판, 망 형태의 부채, 골이 있는 둥근 뇌산호, 짧고 두꺼운 손가락형 군락, 내부 벽과 바닥을 가진 관해면.
- 해초·해조류 5종 형태: 넓은 잎 켈프, 물결치는 리본, 가는 잘피 군락, 붉은 깃털형, 작은 잎과 기낭이 달린 갈조류.
- 말미잘 2종 형태: 사용자가 마지막에 첨부한 사진에 맞춘 **붉은 기둥·분홍색 유연한 촉수**와 **올리브색 기둥·연두/아이보리색 짧고 둥근 촉수**. 납작한 바닥 원반과 카펫형은 제거했습니다. 부착부는 약간 비대칭인 기둥으로 바꾸고 바위·잔돌 틈에 묻었습니다. 부착부→몸통→촉수→끝부분으로 색이 부드럽게 바뀌며, 반점과 과장된 주름은 넣지 않았습니다.

말미잘의 넓고 평평했던 상단 덮개도 제거했습니다. 몸통에서 둥근 타원형 윗면까지 하나의 연결된 곡면으로 이어지며, 촉수는 곡면 높이에 맞춰 밑동이 안쪽에 묻힙니다. 분홍 촉수는 더 도톰한 단면과 완만한 곡선을 사용합니다. 연두 촉수는 별도의 공을 붙이지 않고 단면이 이어지는 둥근 끝으로 마무리했습니다. 별도의 테두리 판이나 얇은 받침은 없습니다. 층층이 자라는 산호도 더 깊게 굽은 곡면과 완만한 물결 모양 테두리로 바꿨습니다.

리본형 잎은 앞·뒤·가장자리와 끝까지 두께가 있는 메시입니다. 판처럼 각져 보였던 잎은 길이 방향을 곡선으로 보간하고, 가로 단면을 얇고 둥글게 말린 형태로 바꿨습니다. 가장자리 굴곡의 진폭도 줄였습니다. 줄기와 촉수는 연속된 단면을 공유하며, 연결점과 끝면에 같은 흔들림 값을 기록합니다. 뿌리와 말미잘 부착부는 고정되고 잎 끝과 촉수는 GPU에서 움직입니다. 개별 촉수 GameObject나 매 프레임 메시 재생성은 없습니다. 관해면 입구와 부채산호의 망 공간은 의도된 생물 형태입니다.

말미잘 군락은 기존 암초 주변과 큰 암반의 낮은 선반에 적당한 간격으로 배치했습니다. 사진처럼 부드럽고 단순한 인상을 유지하도록 두 종류만 사용합니다. 수영 동선·유리벽·입수 준비 공간은 유지합니다. 동물의 실제 종을 정밀 복제한 생물학 모델이 아니라 게임용 형태 변형입니다.

## 1.7 모래·암반 구성

모래는 가까이 촬영된 **4K 입자 색상·노멀 맵**으로 교체했습니다. 원본의 모래 알갱이와 작은 조개 조각을 유지하면서 수중의 밝은 모래색으로 조정하고, 서로 다른 방향·크기의 두 샘플을 섞어 반복이 눈에 띄지 않게 했습니다. 잔물결은 일부 구역에만 얕게 나타나며, 반짝임과 균일한 줄무늬를 줄였습니다. 기존 항공 촬영 모래 재질은 보존되어 있지만 현재 바닥에는 사용하지 않습니다.

실제 바닥은 완만한 퇴적 둔덕과 얕게 파인 부분이 이어지는 메시입니다. 높이는 약 **0.143–0.984 m**이며 플레이어·물고기·카메라·작살이 같은 높이 함수를 사용합니다. 바닥 메시의 중복 정점을 합쳐 형상을 유지하면서 GPU에 전송되는 데이터를 줄였습니다. 작은 자갈 크기도 줄였습니다.

대형 암반은 **3곳에서 7곳**으로 늘었습니다.

1. 서쪽: 높이가 서로 다른 파단면과 좁아지는 정상을 가진 절벽.
2. 동쪽: 첨부 사진처럼 넓게 돌출된 상부, 깊게 파인 하부, 높은 뒤쪽 암벽을 가진 절벽.
3. 중앙: 비대칭 기둥과 기울어진 암반이 이어지는 수중 아치.
4. C자 통로 안쪽: 낮은 암초와 주변 파편.
5. 북서쪽: 단차가 있는 암초 능선.
6. 남서쪽: 무너진 암석층.
7. 남동쪽: 낮은 돌무더기 능선.

각진 절리면을 교차시킨 입체, 기울어진 지층, 가장자리의 깨진 홈과 작은 침식으로 형상을 만들었습니다. 내부의 겹치는 면은 하나의 표면으로 추출합니다. 암석의 색상·노멀 맵은 기존 4K 촬영 재질을 유지했으며, 표면의 음영과 틈의 어둠을 조정했습니다. 추가된 암반과 동쪽 절벽 아래의 수영 공간에도 실제 충돌이 적용됩니다.

## 유지되는 공간과 애니메이션

- 바깥 산책로 포함 78.08 × 53.08 m, 수조 약 68.45 × 42.08 m.
- 수심 기준 12 m. 수면 y=12.04 m, 도보 y=12.275 m, 유리 상단 y=12.02 m.
- C자·S자·오른쪽 도보와 외곽 산책로의 둥근 접합부 및 도보 아래 전체 높이의 유리벽.
- 어두운 관람 복도 38구간, 해양 전시 그림·벤치·문·안내 조명.
- 뿌리가 고정되고 잎이 흔들리는 해초, 반복 상승 기포 140개, 일렁이는 빛줄기와 코스틱.
- 북쪽 입수 준비 데크: 폭 7.8 m, 돌출 3.2 m, 중앙 진입 폭 2.6 m. 앞쪽 지름 5.5 m의 수중 공간을 확보했습니다.

입수 공간은 정적 모델링입니다. 입수 애니메이션·컷신·자동 카메라 전환은 없습니다. 프리팹 `Dive entry staging | static anchors only` 아래의 준비 위치, 발판 끝, 수중 목표, 제안 카메라 구도는 `AquariumEnvironmentRoot`의 `divePreparation`, `diveEdge`, `diveWaterTarget`, `diveCamera`에 연결되어 있습니다.

## 수정과 재생성

대형 해초·말미잘 메시의 저장 파일은 Git 업로드를 위해 여러 `.asset`으로 분할합니다. 분할 전후의 삼각형, 정점 위치, 노멀, 접선, 색상, UV와 흔들림 데이터를 검사하므로 모델 품질은 유지됩니다. 원래 번호의 파일과 `079_part002.asset`처럼 번호가 붙은 추가 파일을 프리팹에서 함께 사용합니다. 메시와 해당 `.meta` 파일, 프리팹, 씬을 함께 커밋해야 하며 수동으로 파일 내용을 잘라 붙이지 않습니다.

재생성 시에도 같은 분할 규칙을 자동 적용합니다. 텍스트 직렬화 예상 크기가 40 MiB를 넘는 메시는 최대 160,000개 정점 또는 480,000개 인덱스 단위로 나눕니다. 경계의 원본 노멀과 애니메이션 값을 복사하여 이음새를 유지하고, 더 이상 쓰이지 않는 자동 생성 분할 파일만 정리합니다. 상세 검증 기록은 `Artifacts/CoralGallery/mesh-partition-validation.txt`에 저장합니다. Git LFS나 별도 파일 조립 과정은 필요하지 않습니다.

메시·재질은 프리팹에서 편집할 수 있습니다. 생성 코드 수정 후 Unity 메뉴 **Aquarium → Coral Gallery → Rebuild and apply map**을 실행하면 프리팹과 두 씬을 갱신합니다. 재생성은 프리팹에 수동 적용한 변경을 덮어쓰므로 커스텀 버전은 먼저 복제하세요.

- `AquariumMapOutline.cs`: 사용자 상단 이미지에서 딴 수조·산책로 경계.
- `AquariumWalkwayLayout.cs`와 `AquariumEnvironment.Architecture.cs`: 중앙 도보와 유리벽, 연결부.
- `AquariumMonolithLayout.cs`: 7개 암반의 입체·기울기·절리·깨진 홈. 메시와 모든 충돌 판정이 공유합니다.
- `AquariumEnvironment.Interior.cs`: 암반 메시 추출과 일관된 면 방향, 암반 위 군락, 관람 복도.
- `AquariumEnvironment.Biodiversity.cs`: 산호 6형태, 해조류 5형태, 말미잘 2형태와 닫힌 유연 메시.
- `LivingReef.shader`: 뿌리가 고정되는 조류 애니메이션과 유기 표면.
- `AquariumMeshAudit.cs`, `AquariumEnvironmentAuthoring.Biodiversity.cs`: 메시 연결·방향 검사와 말미잘의 독립적인 렌더링 동작 검사.
- `AquariumSeabed.cs`: 퇴적 모래 지형의 높이·표면 방향·광선 충돌.
- `AquariumEnvironment.SurfaceDetail.cs`: 모래 메시 및 중복 정점 병합, 촬영 재질 연결.
- `GranularSand.shader`: 4K 모래 입자, 얕고 불규칙한 물결, 낮은 반사.
- `ScannedGeology.shader`: 월드 좌표 기반 암석 색상·노멀·AO/거칠기와 수중 빛.
- `AquariumTextureImport.cs`: 최대 4K, BC7 압축, 밉맵, 비등방성 16배, 색상 sRGB/노멀 선형 설정.

현재 Built-in Render Pipeline의 Windows 데스크톱용입니다. 메시·삼각형·군락 수는 `validation.txt`에 기록합니다. 별도 LOD/모바일 최적화는 포함하지 않았습니다. 멀티플레이 참가자는 동일한 최신 맵 빌드를 사용해야 합니다.

## 검증과 미리보기

51개 게임 검사와 20개 카메라 검사에는 수조 경계, 중앙 유리 통로, 모래 접촉, 7개 암반에서의 탈출·안정된 접촉·빠른 작살 충돌, 동쪽 돌출 선반 아래 수영 경로, 중앙 아치 통과, 플레이어와 물고기의 유효한 시작 위치가 포함됩니다.
