# 숨은 물고기 — 3D / 3인칭 Aquarium Demo

## 바로 실행

- Unity **6000.3.21f1**에서 `Assets/Demos/HideAndSeek/30_HideAndSeek.unity`를 열고 **Play**.
- 허브에서는 **Hide and Seek** 버튼으로 입장.
- Windows 실행 파일이 있다면 `AquariumDemo.exe` 실행. 배포할 때는 exe만 보내지 말고 `AquariumDemo` 폴더 전체를 공유.
- 인터넷 없이 확인하려면 **혼자 연습하기**. 선택한 역할에 맞춰 AI가 들어온다.

## 친구와 인터넷으로 플레이

1. 이름과 역할을 고른다.
2. 한 명이 **인터넷 방 만들기**를 누른다.
3. 생성된 코드를 **코드 복사**로 친구에게 전달한다.
4. 친구는 같은 버전에서 코드를 입력하고 **코드로 참가**를 누른다.
5. 물고기와 술래를 각각 최소 1명씩 배치한다. 참가자는 **준비 완료**, 방장은 **경기 시작**.

2–8명 지원. IP 입력이나 공유기 포트 개방 없이 Unity Relay를 사용한다. 경기 중에는 새 참가자를 받지 않으며, 종료 후 방장이 **대기실로**를 누르면 다시 참가할 수 있다. 방장이 나가면 방이 종료된다.

**모두 3인칭 버전의 최신 실행 파일을 사용해야 한다.** 높이 동기화가 추가되어 이전 고정 시점 빌드와는 연결되지 않는다.

### 최초 Unity Cloud 설정

이 프로젝트는 Unity Cloud의 `PrototypeLab`에 연결되어 있다. 처음 연결하는 복사본이나 다른 Cloud 프로젝트를 사용할 때만 아래 설정을 확인한다.

1. Unity **Edit → Project Settings → Services**에서 조직과 프로젝트를 연결한다.
2. **Dashboard**를 열고 해당 프로젝트를 선택한다.
3. 웹 대시보드의 **Products** 또는 상단 검색으로 **Relay**를 연다. 시작/활성화 안내가 표시되면 진행한다.
4. 익명 로그인(Authentication)을 사용한다. 외부 로그인 공급자 설정은 필요 없다.
5. Unity의 패키지 다운로드와 컴파일이 끝난 뒤 Play한다. Cloud 연결을 바꿨다면 실행 파일도 다시 빌드한다.

사용자 계정의 비밀번호나 서비스 키를 코드에 넣지 않는다. 방 코드는 방장이 접속 중일 때만 유효하다. 오래된 코드, 진행 중인 방, 인원 초과, 끊어진 연결은 메뉴에 안내된다.

공식 설정 참고: [Unity Cloud 프로젝트 연결](https://docs.unity.com/en-us/cloud/projects/configure-project-for-unity-cloud), [Relay와 NGO 연결](https://docs.unity.com/en-us/mps-sdk/tutorials/relay-and-ngo).

## 조작

| 입력 | 동작 |
|---|---|
| WASD | 카메라가 보는 수평 방향을 기준으로 전후좌우 이동 |
| Space / Ctrl | 상승 / 하강 |
| 마우스 | 내 캐릭터 뒤에서 3인칭 시점 회전 / 중앙 조준점 조준 |
| 마우스 휠 | 카메라 거리 조절 |
| Q — 물고기 | 반경 2.8 안의 살아 있는 일반 물고기를 복사 |
| Shift — 물고기 | 일반 물고기처럼 천천히 이동 |
| E — 물고기 | 앞쪽 가까운 물고기 먹기 |
| 왼쪽 클릭 — 술래 | 작살 발사 |
| ESC | 메뉴 열기. 멀티 경기는 계속 진행 |

각 실행 화면의 카메라는 자기 플레이어만 따라간다. 마우스는 경기 중 고정되고 ESC 메뉴·로비·결과 화면에서는 풀린다. 다른 창으로 전환하면 메뉴가 열리며 경기는 계속 진행된다. 초록색 바닥 링이 내 위치다. 술래에게 다른 플레이어의 이름표나 숨는 사람 표시를 보여주지 않는다.

수조 내부를 상하좌우로 자유롭게 헤엄칠 수 있다. 먹기·변신 거리와 작살 적중은 높이를 포함한 3D 거리로 계산한다. 바위 위로 지나가거나 위쪽 물고기를 조준할 수 있다. 카메라는 바위에 가리면 당겨지고, 카메라와 캐릭터 사이의 유리·수면은 해당 화면에서 가려져 시야를 확보한다. 동료에게 삼켜진 동안은 그 동료를 따라가고, 뱉어진 뒤에는 내 캐릭터로 돌아온다. 잡히면 생존한 같은 팀을 관전한다.

## 규칙

- 수조의 일반 물고기 **32마리를 모두 먹으면 물고기 팀 승리**.
- 술래가 모든 숨는 플레이어를 잡거나 **3분**이 지나면 술래 팀 승리.
- 시작 후 **5초**는 물고기가 먼저 움직일 수 있다.
- 이동 속도: 물고기 4, 술래 4.7, 천천히 이동 1.65. 대각선 이동 보정 적용.
- 변신은 가까운 살아 있는 물고기를 복사한다. 변신 직후 잠깐 보라색 외계인이 드러난다.
- **동료를 삼키면 1초 뒤 앞으로 뱉는다.** 보라색 거품 효과와 함께 둘 다 2초 동안 정체가 드러난다. 삼켜진 동안은 이동·공격할 수 없다.
- 동료를 삼킨 채 잡히거나 접속이 끊어져도 동료는 풀려난다. 연쇄 삼키기는 금지한다.
- 술래는 일반 물고기도 작살로 죽일 수 있다. **죽은 물고기는 바닥에 남고 먹을 수 있다.** 먹이 목표가 불가능해지는 것을 방지하는 데모 규칙이다.
- 작살은 가장 먼저 맞은 물고기 또는 바위에 막힌다. 숨는 사람끼리의 위치 충돌은 막지 않는다.
- 잡힌 플레이어는 관전한다. 술래가 모두 퇴장하면 남아 있는 물고기 팀이 승리한다.

## 개발 구조

| 파일 | 책임 |
|---|---|
| `Assets/Demos/HideAndSeek/Scripts/AquariumModel.cs` | Unity에 의존하지 않는 게임 규칙, 이동, 먹기, 삼키기, 작살, 승패, AI |
| `AquariumSession.cs` | Relay 코드 생성·참가, NGO 메시지, 준비·역할, 방장 판정, 상태 동기화 |
| `AquariumView.cs` | 기본 도형 수조, 물고기/외계인/술래 모델, 높이·회전 표시, 변신·트림 효과 |
| `AquariumThirdPersonCamera.cs` | 로컬 플레이어 3인칭 추적, 회전·줌·엄폐 보정, 카메라 기준 입력과 3D 조준 |
| `AquariumGame.cs` | 메뉴, 로비, HUD, 입력, 간단한 효과음 |
| `AquariumSmokeDriver.cs` | 개발 빌드 전용 자동 접속·실행 검사. 일반 실행에서는 비활성 |
| `Assets/Demos/HideAndSeek/Editor/AquariumBuild.cs` | **Aquarium → Build Windows Demo** 빌드 메뉴 |
| `Tests/ModelTests.cs` | 핵심 규칙 회귀 검사 |

방장이 30Hz로 규칙을 계산하고 약 10Hz로 상태를 전송한다. 클라이언트는 방향·행동만 요청하며 이동 속도, 적중, 먹기, 승패를 결정하지 않는다. 화면은 상태 사이를 보간한다. 패키지는 NGO 2.7.0, Multiplayer Services 1.2.0이며 `Packages/packages-lock.json`도 Git으로 공유한다.

아트는 Play할 때 기본 도형과 자체 생성 메시로 만들어진다. 별도 다운로드나 외부 모델 라이선스가 필요 없다. 아트 교체는 `AquariumView`에 집중하면 된다. 게임 수치 변경은 `AquariumModel`의 상수와 각 행동 메서드에서 가능하다.

## 빌드와 검사

- Unity 메뉴 **Aquarium → Build Windows Demo**: 프로젝트 옆 `AquariumDemo` 폴더에 Windows 개발 빌드를 생성한다.
- 규칙 검사: 프로젝트 루트에서 PowerShell `./Tests/Run-ModelTests.ps1` 실행. Unity 설치 위치가 다르면 스크립트의 경로를 조정한다.
- 두 실행 파일 또는 Unity Editor + 실행 파일로 방 코드 접속을 확인할 수 있다. 각각 임시 익명 로그인 프로필을 사용하므로 같은 PC에서도 서로 접속할 수 있다.

## 데모 범위

Windows PC, 한 수조, 3인칭 3D 자유 수영, 최대 8명 기준이다. 전용 서버, 방장 이전, 진행 중 재접속, Steam 초대, 음성 채팅, 계정 저장, 매치메이킹은 구현하지 않았다. AI는 연습 모드에만 들어온다. 숨은 플레이어 위치까지 포함한 상태를 참가자에게 전송하므로 상용 수준의 정보 은닉·부정행위 방어는 후속 작업이다.

## 확인한 내용 — 2026-09-28

- Unity 6000.3.21f1에서 Windows 빌드 성공.
- 독립적인 규칙 검사 17개 통과: 기존 먹기·삼키기·작살·승패 규칙과 함께 3축 이동 속도 보정, 수면/바닥 제한, 수직 먹기, 높이가 다른 목표물 조준, 바위 위 통과를 검사했다.
- 카메라 검사 9개 통과: 소유 플레이어 추적, 화면별 회전 독립성, 카메라 기준 이동, 각도 제한, 삼킨 동료 추적과 복귀, 같은 팀 관전, 로비 복귀.
- 같은 PC의 두 별도 실행 프로세스가 **실제 Unity Relay**를 통해 방 코드로 접속했다. 참가자는 상태 갱신 120회, 참가자 2명, 자신의 카메라 추적 ID 2를 기록했다. 높이는 0.65–6.5까지 변했고 오류 0건이었다. 방장 카메라 추적 ID는 1로 확인했다.
- 3인칭 게임 카메라로 수조·캐릭터·효과를 별도 렌더링해 확인했다. 수면 가까이 올라갔을 때의 시야도 보정했다. 제공하는 미리보기는 HUD를 제외한 화면이다.
- 다른 두 PC/서로 다른 인터넷 회선, 8인 부하, 장시간 플레이는 아직 검증하지 않았다.

## 두 사람 작업

- 공통 시작점은 `main`. 예: `feature/aquarium-art`, `feature/aquarium-rules`에서 작업 후 병합.
- Scene과 `.meta`를 함께 커밋한다. `Library`, `Temp`, 실행 파일 빌드 폴더는 Git에 넣지 않는다.
- 같은 Scene을 동시에 수정할 때는 먼저 합의한다. 현재 아트와 규칙은 별도 파일이라 독립적으로 작업하기 쉽다.
- 다른 장르 Scene과 데모 코드는 그대로 별도로 유지된다.
