# 물고기 술래잡기 — 데모 v0.1

`수족관_술래잡기_게임기획서_v0.1.pdf`(2026-10-15 작성)를 기준으로 2026-10-16에 다시 만든 Windows 데모다. 외계인 4명이 물고기로 위장해 먹이를 먹고, 잠수부 1명이 행동의 차이를 찾아 작살로 잡는다. 잠수부는 1인칭, 외계인은 3인칭으로 수조 안을 자유롭게 헤엄친다.

이번 개선판은 이동·시점의 부드러운 가감속, 중앙에 가까운 외계인 시점, 변신 대상 한 마리의 노란 윤곽선, 준비 시간 포식 금지, 근거리 먹이 효과음, 사망 후 2.5초 연출과 정지된 경기 결과 자유시점을 반영했다.

## 바로 실행

1. `Build/Aquarium-controls-ui/AquariumDemo.exe`를 실행한다.
2. 이름과 역할을 고른다.
3. **AI 연습 시작**을 누른다. 인터넷 없이 외계인 4명 + 잠수부 1명을 체험할 수 있다.

공유할 때는 `Build/Aquarium-controls-ui` **폴더 전체**를 전달한다. exe만 옮기면 실행되지 않는다. 이전 `Aquarium-v0.1-Windows.zip`에는 이번 조작·UI 변경이 포함되어 있지 않다.

Unity에서는 **6000.3.21f1**로 프로젝트를 열고 `Assets/Demos/HideAndSeek/30_HideAndSeek.unity`에서 Play를 누른다. 허브의 **Hide and Seek** 버튼으로도 입장할 수 있다. 시작 메뉴의 규칙 안내에서도 데모 수치를 확인할 수 있다.

## 조작

| 입력 | 동작 |
|---|---|
| W | 바라보는 방향으로 전진 — A/S/D 이동 없음 |
| 마우스 | 시점 회전·중앙 조준점 조준 |
| Shift | 스태미나를 사용하는 질주 — 두 역할 공통 |
| 왼쪽 Alt — 외계인 | 천천히 이동 |
| 마우스 휠 — 외계인 | 3인칭 카메라 거리 조절 |
| Q — 외계인 | 노란 테두리로 표시된 물고기의 모습 복사 |
| E — 외계인 | 앞의 일반 물고기 먹기 / 동료 삼키기 — 숨을 시간에는 사용 불가 |
| R — 외계인 | 조건을 만족하면 부활용 알 낳기 |
| 왼쪽 클릭 — 잠수부 | 작살 발사 |
| F — 잠수부 | 앞에 먹이 뿌리기 |
| R — 잠수부 | 생명체 위치 탐지 |
| ESC | 메뉴 열기·닫기 |

마우스는 경기 중 고정된다. ESC를 누르거나 다른 창으로 전환하면 메뉴가 열리고 마우스가 풀린다. 메뉴를 열어도 경기는 계속 진행된다. 잠수부의 몸은 자신의 1인칭 시야를 가리지 않으며, 외계인은 자신의 위치 링으로 조종 중인 캐릭터를 구별할 수 있다.

마우스로 위를 보며 W를 누르면 상승하고, 아래를 보며 W를 누르면 하강한다. 정면을 보면 높이를 유지하며 전진한다. 결과 화면의 자유시점도 같은 이동 방식을 사용한다. Shift 질주와 외계인의 왼쪽 Alt 느린 이동은 그대로 사용할 수 있다.

이동은 짧은 가감속을 적용하며, 시점 회전·확대도 부드럽게 이어진다. 외계인 카메라는 좌우 중앙에서 거의 정면으로 바라보며 시작 거리는 4.2m다. 바위가 카메라 앞을 막으면 즉시 거리를 줄인다.

일반 물고기의 모든 종류와 외계인의 기본 이동속도는 **4m/s**다. 일반 물고기는 잠수부를 피할 때 방향만 바꾸며 같은 속도를 유지한다. 화면의 스태미나·허기는 아이콘과 막대·숫자로 확인하고, 행동 키와 재사용 대기시간은 하단 카드에 표시한다. 개인 순위는 결과 화면에서 확인한다.

## 친구와 인터넷으로 플레이

1. 이름과 역할을 고른 뒤 한 사람이 **온라인 방 만들기**를 누른다. 방 이름은 **1–32자**로 입력한다. 비밀번호는 선택 사항이며, 설정하려면 **8–64자**, 공개 방으로 만들려면 빈칸으로 둔다.
2. 친구는 오른쪽 **방 목록**에서 대기 중인 방의 이름·현재 인원·비밀번호 여부를 확인하고 원하는 방의 **참가**를 누른다. **경기가 시작된 방은 목록에서 숨겨지고, 방장이 대기실로 돌아오면 다시 표시된다.** 메뉴의 목록은 **5초마다 자동 갱신**되며 **새로고침**으로 직접 갱신할 수도 있다. 방 생성·참가 창이나 규칙 안내를 연 동안, 연결 중, 접속 후에는 자동 갱신을 멈춘다. 비밀번호 방은 비밀번호를 입력해야 입장할 수 있다.
3. 기존 **코드로 참가**도 사용할 수 있다. 방장은 대기실의 **코드 복사**로 받은 Relay 코드를 친구에게 전달한다. **비밀번호 방은 코드로 참가할 때도 같은 비밀번호가 필요하다.** 공개 방은 비밀번호를 비워 둔다.
4. 대기실에서 잠수부를 **정확히 1명**, 외계인을 최소 1명 배치한다. 참가자는 **준비 완료**, 방장은 **경기 시작**을 누른다. 선택한 역할이 이미 차 있으면 화면에 안내되는 배정을 확인하고 대기실에서 역할을 조정한다.

방에는 **관전자를 포함해 사람 최대 5명**이 접속할 수 있으며, 인터넷 경기는 사람 **2–5명**으로 시작한다. 시작할 때 부족한 외계인 자리는 AI가 채워 **항상 외계인 4명 + 잠수부 1명**이 된다. AI는 사람 접속 정원에 포함하지 않는다. 연습에서는 선택한 역할을 제외한 자리가 AI로 채워진다. 인터넷 경기에서 추가된 AI는 대기실 복귀 때 제거되어 다음 경기 인원을 다시 정할 수 있다.

**진행 중인 방은 목록에 표시되지 않지만, 빈자리가 있으면 기존 방 코드로 참가할 수 있다.** 코드로 들어오면 우선 관전하며, 현재 경기에서 캐릭터를 조종하지 않는다. 결과 화면 중 참가한 경우에도 다음 대기실을 기다린다. 방장이 대기실로 돌아오면 역할을 배정받고 준비하여 다음 경기에 참가할 수 있다.

Unity Relay를 사용하므로 IP 입력이나 공유기 포트 개방이 필요 없다. **방장이 접속을 유지하는 동안에는 다른 사람의 입·퇴장과 대기실 복귀·재대결에도 같은 방과 코드가 유지된다.** 방장이 방을 나가거나 게임을 종료하면 방이 닫히며, 방장 이전은 지원하지 않는다. 새로 만든 방에는 새 코드가 발급된다. 목록의 인원·상태는 조회 시점의 정보이며 실제 참가할 때 다시 확인한다.

**통신 프로토콜은 v6다. 모두 이번 최신 실행 파일을 사용해야 하며 이전 빌드와 연결되지 않는다.** 실제 인터넷 접속 검증 범위는 배포본의 `검증결과.txt`를 따른다.

### Unity Cloud 설정

프로젝트는 Unity Cloud의 `PrototypeLab`에 연결되어 있다. 다른 Cloud 프로젝트로 바꾸거나 새 복사본에 서비스 연결이 없는 경우 Unity의 **Edit → Project Settings → Services**에서 조직과 프로젝트를 연결하고 대시보드에서 **Lobby와 Relay**를 활성화한다. 방 목록·비밀번호는 Lobby를, 경기 통신은 Relay를 사용하며 Authentication의 익명 로그인으로 접속한다. 연결 설정을 바꾼 뒤에는 실행 파일을 다시 빌드한다.

## 경기 규칙

### 위장·먹기·허기

- 시작 후 **5초**는 외계인이 먼저 움직이고 위장하는 숨을 시간이다. **외계인의 일반 포식·동료 삼키기는 모두 금지**하며, 잠수부의 이동·작살·먹이·탐지도 제한한다. 이때 누른 포식 입력은 준비 종료 후 자동 실행되지 않는다. AI에도 같은 규칙을 적용한다.
- Q는 앞쪽 **2.8m** 안에서 조준 방향에 있는 살아 있는 일반 물고기 또는 물고기로 위장한 동료를 복사한다. 조준점에 가까운 후보 **한 마리만 노란 테두리**로 표시하고 실제 Q 입력도 그 대상을 사용한다. 입력 후 대상이 사라지거나 범위를 벗어나면 다른 물고기로 임의 변경하지 않는다. 바위 뒤 대상은 복사할 수 없다. 두 종류에 같은 테두리와 변신 효과를 사용하며, 상대의 정체를 알려주지 않는다. 변신한 본인은 0.65초 동안 잠깐 외계인 모습이 드러난다.
- 일반 물고기를 먹으면 **2초 경직**되어 이동·질주·먹기·변신·산란을 할 수 없다. 먹는 동작과 **5초간 남는 빨간 흔적**이 잠수부의 단서가 된다. 위장한 물고기 종류 자체는 유지된다.
- 정상 포식은 개인 포식량을 1 늘리고 허기를 채운다. **60초 동안 일반 물고기를 먹지 못하면 굶어 죽는다.** 첫 허기 시간은 5초 준비가 끝날 때 시작한다. 동료를 삼키거나 알을 낳는 행동은 허기를 채워주지 않는다.
- 작살에 맞은 일반 물고기는 시체가 작살에 붙어 잠수부에게 함께 회수된 뒤 바닥으로 가라앉으며 다시 먹을 수 없다. 위장한 외계인 시체도 함께 회수된다. 잠수부가 죽인 일반 물고기 수만큼 팀의 먹이 목표가 감소하므로 이중으로 계산하지 않는다.

### 동료 삼키기

- 동료를 삼키면 **둘 다 즉시 위장이 풀리고 3초 경직**된다. 피해자는 먹은 동료의 위치에 따라가며 행동할 수 없다.
- 3초 뒤 피해자를 앞으로 뱉고 **노란 흔적이 5초** 남는다. 이후 이동과 질주는 가능하지만, **삼킨 순간부터 총 6초** 동안 둘 다 변신할 수 없다. 뱉어진 후 추가로 약 3초의 변신 제한이 남는다.
- 삼킨 사람만 **150점 감점**된다. 삼켜진 사람은 감점되지 않으며, 누구의 허기도 초기화하지 않는다.
- 동료를 품은 채 다시 삼키는 연쇄 행동은 막는다. 운반자가 잡히거나 퇴장해도 삼켜진 동료는 풀려난다.

### 알과 부활

- 본인이 일반 물고기를 **3마리 이상** 먹었고, 아직 다른 알에 예약되지 않은 사망 외계인이 있을 때 R로 알을 낳는다. 경직 중이거나 삼켜진 상태에서는 사용할 수 없다.
- 산란은 **플레이어당 경기 전체에서 1회**다. 포식량 3은 자격 조건이며, 산란해도 포식량이나 팀 먹이 목표를 차감하지 않는다.
- 산란한 알은 **초당 1.2m**로 가라앉아 모래 바닥이나 바위 표면에 닿으면 멈춘다. 방장이 위치를 계산해 모든 참가자에게 동기화하며, 경기 종료 시 하강도 정지한다.
- 알 하나가 사망한 동료 **한 명을 예약**하고 **산란 12초 뒤 현재 알 위치에서 그 동료를 부활**시킨다. 같은 사망자를 여러 알이 동시에 예약하지 않는다.
- 잠수부의 작살 **1회 적중**으로 알이 파괴된다. 부화에 성공하면 알 주인에게 **150점**을 준다. 알 주인이 이미 퇴장했다면 부화는 진행되지만 점수를 받을 플레이어가 없으므로 지급하지 않는다.
- 부활한 사람은 허기 시간과 스태미나를 가득 채운다. **기존 점수·개인 포식량·산란 사용 여부는 유지**하며, 생명당 노출 점수 상한만 초기화한다.
- 예약된 사망자가 퇴장하거나 이미 살아 있으면 알은 제거되고 산란 기회는 환불하지 않는다. 알 주인의 퇴장만으로 알이 제거되지는 않는다.
- 살아 있는 외계인이 없어도 **부활 가능한 알이 남아 있으면 경기 중**이다. 외계인과 알을 모두 없애야 전멸 승리한다.

### 잠수부의 도구와 AI

- 작살 쿨타임은 **3초**다. 가장 먼저 맞은 외계인·일반 물고기·알에 적용되고 바위에 막힌다. 높이를 포함한 3D 판정을 사용한다.
- 먹이 뿌리기는 **20초 쿨타임 / 5초 지속 / 6m 유인 반경**이다. 살아 있는 일반 물고기만 모이며 외계인은 자동으로 끌려가지 않는다. 일반 물고기는 가까운 잠수부를 피해 움직이지만 먹이가 있으면 유인이 우선한다.
- 먹이를 뿌린 지점에서 **10m 안에 있는 플레이어**에게 물방울 효과음이 들린다. 높이를 포함한 거리가 멀어질수록 작아지고 10m 이상에서는 들리지 않는다. 관전 중에는 관전 대상의 위치를 기준으로 들린다.
- 탐지는 **5초 지속 / 18초 쿨타임 / 22m 반경**이다. 화면 안의 일반 물고기·외계인·알을 **같은 중립 표식**으로 표시하며 외계인 여부나 이름을 붙이지 않는다. 탐지 표식 자체로 노출 점수를 주지 않는다.
- 연습 잠수부 AI는 자기 시야와 거리 안에서 바위에 가리지 않는 외계인 모습·먹는 행동·알을 단서로 삼는다. 위장된 위치나 탐지 표식만으로 정체를 판별하지 않는다.

### 승리·종료

- 초기 일반 물고기는 **32마리**다. 먹은 수가 `32 - 잠수부가 죽인 일반 물고기 수`에 도달하면 외계인 팀이 승리한다. 마지막 일반 물고기를 잠수부가 죽여도 외계인의 먹이 목표가 달성될 수 있다.
- 살아 있는 외계인과 남은 알이 모두 없으면 잠수부가 승리한다. 먹이 목표 달성과 전멸이 같은 판정에 생기면 **전멸을 먼저 판정**한다.
- 준비 시간 후 **180초**가 지나면 잠수부 승리다. 잠수부가 모두 퇴장하면 남아 있는 외계인 팀이 승리한다.
- 경기 중 외계인이 죽으면 **사망 당시 모습의 시체가 남는다.** 본인 카메라는 약 **2.5초 동안 3인칭으로 물러나며 시체를 보여준 뒤 잠수부 시점으로 관전**한다. 부활하면 시체가 사라지고 본인의 조작·시점으로 돌아온다.
- **실제로 경기가 종료되는 순간에는 사망 연출을 생략**하고 즉시 결과를 표시한다. 마지막 외계인이 죽어도 부활 알이 남으면 경기가 계속되므로 일반 사망 연출을 적용한다.
- 종료 후에는 **20초 자유시점**으로 종료 순간을 둘러본다. 죽은 외계인·물고기는 숨기고, 생존자의 당시 모습과 수조 전체를 정지한다. 물고기 움직임·꼬리·촉수·먹는 동작·알·흔적·거품·수초도 멈추며 카메라만 자유롭게 움직인다.
- 20초 후 결과에서 방장은 **대기실로**, 연습 플레이어는 **다시 연습**을 선택할 수 있다.

## 개인 점수와 화면 공개 범위

| 행동 | 점수 |
|---|---:|
| 일반 물고기 1마리 먹기 | +100 |
| 동료 삼키기 | 삼킨 사람만 -150 |
| 알 부화 성공 | 알 주인 +150 |
| 잠수부의 실제 시야 안에 머물기 | 누적 2초마다 +5, 생명당 최대 +50 |

노출 점수는 위장 여부와 관계없이 살아 있는 외계인에게 적용한다. 잠수부가 바라보는 방향과 대상 방향의 내적이 **0.8 이상**, 거리 **12m 이내**, 바위에 가리지 않을 때 노출 시간을 누적한다. 탐지는 이 조건을 대신하지 않는다. 이 수치는 데모의 임시 해석이며 실제 화면 픽셀의 가시성을 검사하는 방식은 아니다.

현재 데모는 **외계인 개인 순위·팀 먹이 진행도·살아 있는 외계인 수·알 수를 양쪽 화면에 공개**한다. 각 이름이나 점수를 수조 속 물고기에 연결하는 정체 표식은 경기 중 제공하지 않는다. 정보 공개 범위는 후속 밸런스 검토 대상이다.

## 기획서의 미정 사항에 적용한 데모 수치

아래 값과 처리 방식은 체험과 검증을 위해 정한 **임시 결정**이다. 기획서가 확정한 값으로 해석하지 않는다.

| 항목 | 이번 데모의 결정 |
|---|---|
| 제한 시간·먹이 수·시간 만료 승자 | 180초 / 32마리 / 잠수부 승리 |
| 기본 속도·질주 | 외계인 4, 잠수부 4.7, 외계인 느린 이동 1.65 / 질주 1.6배 |
| 스태미나 | 최대 100 / 질주하며 이동할 때 초당 25 소모 / 회복할 때 초당 18 회복. 제자리나 벽에 막힌 이동은 소모하지 않음. 모두 소모한 채 질주 입력을 유지하면 기본 속도로 이동하며, 입력을 풀어 회복 |
| 산란·부화·파괴 | 개인 3마리 포식 / 사망 동료 1명 예약 / 12초 부화 / 작살 1회 파괴 / 산란 1회는 부활해도 재충전하지 않음 |
| 부활 보존·초기화 | 점수·포식량·산란 사용 여부 유지 / 허기·스태미나와 생명당 노출 점수 상한 초기화 |
| 탐지 | 5초 / 쿨타임 18초 / 22m / 일반 물고기·외계인·알에 동일 표식 |
| 점수 | 포식 +100 / 동족 포식 -150 / 부화 시 알 주인 +150 / 노출 누적 2초마다 +5, 생명당 최대 +50 |
| 시야 노출 | 위장 여부 무관 / 12m / 방향 내적 0.8 이상 / 바위 가림 적용 / 탐지로 대체하지 않음 |
| 동시 승리 조건 | 외계인·알 전멸 → 먹이 목표 → 잠수부 퇴장 → 시간 만료 순서 |
| 정보 공개 | 양쪽 모두 개인 순위·팀 진행도·생존 인원·알 수 확인 가능, 경기 중 물체별 정체 표식 없음 |

## 개발 구조와 검증

| 파일 | 책임 |
|---|---|
| `Assets/Demos/HideAndSeek/Scripts/AquariumModel.cs` | Unity 비의존 규칙, 허기·스태미나·점수·알·승패·AI |
| `AquariumSession.cs` | Relay 연결·코드 유지, 준비·역할·중도 관전, 방장 판정, 프로토콜 v6 동기화 |
| `AquariumRooms.cs` | Lobby 방 생성·목록 조회·비밀번호·인원·진행 상태 관리 |
| `AquariumView.cs` | 수조·캐릭터·흔적·알·먹는 동작의 시각 표현 |
| `AquariumThirdPersonCamera.cs` | 역할별 시점, 관전·부활, 종료 후 자유시점, 3D 조준 |
| `AquariumGame.cs` | 방 목록·생성·참가·비밀번호 메뉴, 한국어 규칙 안내·HUD·순위·중립 탐지 표식·입력·효과음 |
| `AquariumSmokeDriver.cs` | 개발 빌드의 자동 연습·접속·캡처 검사 |
| `Assets/Demos/HideAndSeek/Editor/AquariumBuild.cs` | **Aquarium → Build Windows Demo** 메뉴 |
| `Tests/ModelTests.cs` | 게임 규칙 회귀 검사 |

방장이 30Hz로 규칙을 계산하고 약 20Hz로 상태를 보낸다. 참가자는 입력만 전송하며 이동·적중·점수·알·승패는 방장이 결정한다. 아트는 실행할 때 기본 도형과 생성 메시로 구성한다.

- **규칙 검사:** 프로젝트 루트에서 `./Tests/Run-ModelTests.ps1`. **49개 통과.** 허기, 포식 제한, 조준 복사, 질주·가감속, 점수 상한, 알 예약·부화·파괴, 전멸 보류, 사망 외형·종료 정지, 소리 거리, AI의 시야 제한을 검사한다.
- **카메라 검사:** 빌드 시 **32개 통과.** 중앙 시점·회전과 확대 보간·사망 후 관전·부활·알이 남은 전멸·종료 순간 시점 보존을 검사한다.
- **Windows 빌드:** Unity 메뉴 **Aquarium → Build Windows Demo**. 기본 출력은 `Build/Aquarium-v0.1/AquariumDemo.exe`이며 `AQUARIUM_BUILD_PATH`로 다른 위치를 지정할 수 있다. 빌드 전에 카메라 검사를 실행한다.
- **최종 실행·카메라·접속 검증:** 배포 폴더의 [검증결과.txt](../Build/Aquarium-v0.1/검증결과.txt)를 확인한다. 이전 버전의 실행 기록을 이번 빌드의 통과 근거로 사용하지 않는다.

Windows PC와 한 수조를 대상으로 한 데모다. 전용 서버·방장 이전·끊긴 연결의 자동 복구·Steam 초대·음성 채팅·계정 저장·자동 매치메이킹은 범위에 포함하지 않는다. 숨은 플레이어 상태도 참가자에게 전송하므로 상용 수준의 정보 은닉·부정행위 방어는 후속 작업이다.
