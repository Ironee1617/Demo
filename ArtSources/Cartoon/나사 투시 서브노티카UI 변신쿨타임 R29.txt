R29 — 나사 투시 테두리 · 배수구 안내 정리 · 서브노티카풍 UI · 변신 쿨타임 (2026-10-28)

[요청]
1. 나사 가까이 가면 나사 테두리가 캐릭터를 넘어서도 보이게
2. 너무 멀리서 조준할 때 "더 가까이" 문구 안 뜨게
3. 나사 푸는 중에도 다른 나사를 조준하면 그 나사의 진행도 보이게
4. 외계인(위장한 동료)을 포식해도 배고픔이 차지 않게
5. 작살 첫 대는 끌려가지 않게
6. 전체 UI를 서브노티카 느낌으로
7. 변신 쿨타임 10초, 해제는 언제든

[변경]
- 나사 투시 테두리 (Resources/AquariumTargetOutlineXRay.shader, Drains/Runtime/AquariumDrain.cs)
  · 외계인이 배수구 5m 안(1.5m 동안 서서히)에 들어오면 남은 나사마다 하늘색 테두리. 깊이 무시라 촉수/몸 뒤에서도 보임.
  · 가려진 부분만 은은하게 채워져 "몸 뒤에 있다"는 게 읽힘. 보이는 나사는 테두리만.
  · 조준한 나사는 노란색(더 두껍게). 와셔·나사대는 빼고 육각 머리만 둘러쌈. 뚜껑이 움직이기 시작하면 사라짐.
- 배수구 안내 (Scripts/AquariumGame.cs, AquariumModel.Drains.cs)
  · 거리 밖이면 문구 없이 그냥 "사용 불가" 처리 (더 가까이 삭제).
  · 조준한 부품: 회색 링 + 조준점 아래 [F] 동작 / 그 아래 "나사 2 · 0% · 남은 20.0초 · 풀린 나사 2/6".
  · 작업 중인 부품: 하늘색 링 + 퀵슬롯 위 고정 카드(원형 게이지·남은 초·이름·[F] 놓기). 작업 중에도 다른 나사를 조준하면 그 나사 정보가 따로 보이고, F를 누르면 그 나사로 옮김("이 나사로 옮기기").
- 규칙 (Scripts/AquariumModel.cs, AquariumModel.Drains.cs)
  · 동료 포식: 점수 -150은 유지, 배고픔 회복 없음. 물고기는 그대로 +50.
  · 변신 성공 시 다음 변신까지 10초 (실패하면 0.5초). Q 슬롯에 남은 시간 막대.
  · C 해제: 경직·먹는 중·산란 중·배출 반동 중에도 바로 됨 (삼켜진 상태·사망만 불가).
  · 작살 첫 대: 모델상 원래 끌려가지 않음(맞은 뒤 3초간 이동 0 확인). 체감되던 "당겨짐"은 배수구에 끼어 있다 맞았을 때 위로 0.9m 튀어 오르며 속도 3.2를 받던 연출 → 그 자리(입구 바로 위)에 멈추도록 수정. 두 번째 대는 기존대로 사망 + 회수.
- UI (Scripts/AquariumGame.cs)
  · 반투명 심해 유리 카드 + 얇은 하늘색 테두리 + 둥근 모서리 (IMGUI 둥근 사각형, 해상도 무관하게 선명).
  · 왼쪽 아래 원형 생존 게이지: 배고픔(큰 링, 포식 가능 지점 점 표시) · 스태미나 · 생명(2칸 링). 잠수부는 스태미나.
  · 위 가운데 나침반 띠(카메라 방향, N/NE/E…) + 시계 알약. 잠수부에게는 탈출 지점이 나침반에 주황 점으로도 표시.
  · 퀵슬롯형 스킬 칸(키캡·이름·상태·재사용 막대, 준비되면 테두리 점등), 원형 조준점, 알약형 상호작용 안내.
  · 메뉴·방 목록·방 대화상자·대기실(다른 세션의 외계인 선택 화면 포함)·규칙·결과 화면 모두 같은 스타일.

[병합]
- 작업 중 다른 세션(외계인 종류/선택 대기실)이 AquariumGame/Model/View를 바꿈 → 3-way 병합. 대기실은 그쪽 레이아웃 그대로 두고 스타일만 맞춤, 역할 카드에 외계인 종류 이름 유지.
