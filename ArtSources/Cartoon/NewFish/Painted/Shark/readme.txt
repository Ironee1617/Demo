상어 색칠 완성본

기준 그림: shark-large-turnaround-v2 / four-views.png
원본 모델 형태와 크기를 유지하고 UV, 색칠 텍스처, 무광 재질을 추가했습니다.
푸른 회색 몸통 / 크림색 배 / 옅은 눈과 작은 검은 눈동자 / 아가미 3줄 / 지느러미 2줄 무늬 / 분홍빛 입 안쪽

파일
- cartoon_shark_colored.blend: 편집용 Blender 파일. 컬러 텍스처가 파일 안에 포함되어 있습니다.
- cartoon_shark_colored.fbx: Unity 등에서 가져올 수 있는 모델.
- cartoon_shark_colored.glb: 컬러 텍스처가 포함된 단일 파일 모델.
- cartoon_shark_colored.obj + .mtl: OBJ 형식 모델과 재질. 두 파일과 PNG를 함께 보관하세요.
- Shark_BaseColor.png: 4096 x 4096 컬러 텍스처.
- preview_*.png: 완성 모델의 실제 렌더 미리보기.

Unity에서 사용하기
1. FBX와 Shark_BaseColor.png를 같은 Assets 하위 폴더에 넣습니다.
2. 재질의 Base Map 또는 Albedo가 비어 있으면 Shark_BaseColor.png를 연결합니다.
3. 텍스처의 sRGB는 켜고 Metallic은 0, Smoothness는 약 0.14로 설정하면 무광 느낌에 가깝습니다.

원본 OBJ와 MTL은 상위 폴더에 그대로 보존되어 있습니다.
리깅과 애니메이션은 추가하지 않았습니다.
