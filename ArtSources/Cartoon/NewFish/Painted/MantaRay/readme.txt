가오리 색칠 완성본

기준 그림: fish-seven-turnarounds-v1/03-ray/four-views.png
원본 모델의 형태와 크기를 유지하고 UV, 4K 컬러 텍스처와 무광 재질을 추가했습니다.

ray_colored.blend : Blender 편집용. 텍스처가 파일 안에 포함되어 있습니다.
ray_colored.fbx : Unity 등에서 가져올 모델입니다.
ray_colored.glb : 텍스처가 포함된 단일 모델 파일입니다.
ray_colored.obj + ray_colored.mtl : OBJ 모델과 재질입니다. PNG와 함께 보관하세요.
ray_BaseColor.png : 4096 x 4096 컬러 텍스처입니다.
preview_*.png : 색칠한 실제 모델의 렌더 미리보기입니다.

Unity: FBX와 PNG를 같은 Assets 하위 폴더에 넣으세요. 재질의 Base Map 또는 Albedo가 비어 있으면 PNG를 연결하면 됩니다.
텍스처 sRGB 켜기 / Metallic 0 / Smoothness 약 0.14.
원본 OBJ와 MTL은 상위 폴더에 보존됩니다. 리깅과 애니메이션은 추가하지 않았습니다.
