# R53 — 파랑 추적 잠수부 · 분홍 드론 잠수부 모델 (2026-10-31)

## 요청
- `D:\수족관술래잡기\scuba diver 3d model`(파랑) → 탐지 스킬 잠수부(추적, kind 1)
- `D:\수족관술래잡기\pink diver cartoon 3d model`(분홍) → 드론 잠수부(kind 2)
- 리깅·맵핑·애니메이션 전부, 파랑 발 옆 떨어진 폴리곤 제거, 작살총은 기존 복사 + 색만 다르게

## 만든 방법 (Python, 스크립트는 각 모델 폴더 `Edited/`)
- Tripo OBJ(텍스처 없음) → 정점 용접, 떨어진 조각 제거(파랑: 발 옆 x=±0.16 의 1~2면 조각 2개), 오목 주름 32°로 부품 분할.
- 칠: 부품 번호 + 위치 규칙(`rules_blue.py / rules_pink.py`)으로 색 점수 → 1단계 세분(약 4.2만 삼각형) 위에서 색 경계를 등고선으로 잘라 넣음(R52 노랑과 같은 "칠 = 기하" 방식, 경계가 선명). 색별 평면 견본 256px 아틀라스, 렌즈는 세로 그라데이션 + 하이라이트 두 개.
  - 파랑: 크림 헬멧 + 고글 둘레 파란 후드/윗머리 줄, 얼굴 살색·분홍 코·갈색 콧수염, 검은 끈·이어피스·호스·하네스, 은색 고글테·버클, 파란 슈트 + 크림 앞판 + 크림 손목 쪽 소매, 검은 장갑·발목, 파란 오리발(검은 발주머니), 파란 탱크(검은 띠·바닥).
  - 분홍: 같은 구성 + 미소 입, 귀 옆 갈색 머리, 가슴~배 크림 앞판과 허리 뒤 크림, 분홍 슈트/탱크/오리발.
- 뼈: 노랑과 같은 17개 이름·계층(Root, Body, Head, 팔·다리 L/R). 크기는 노랑과 같은 키(발 −0.92 ~ 머리 +0.91, 피벗 동일).
- 웨이트: 부품별 고정(머리 부품→Head, 탱크·하네스→Body, 장갑→Hand, 오리발 Flipper→FinTip 경사) + 슈트는 어깨/팔꿈치/손목/엉덩이/무릎/발목 경사 후 표면 스무딩, 하네스류는 아래 슈트 웨이트를 따라감.
- 총 잡는 손(HandL): 노랑과 같은 방식으로 손가락을 손잡이 둘레로 말아 둠. 총 소켓 회전은 노랑과 같고 위치만 새 손에 맞춤.

## Unity
- 새 편집기 `Equipment/Editor/DiverVariants.cs` (메뉴 Aquarium/Characters/Apply tracker + drone divers), 데이터 `ArtSources/Cartoon/DiverVariants/{Tracker,Drone}`.
- 생성: `Diver_Tracker / Diver_Drone` 프리팹·메시·재질, 노랑 클립 13개를 각자 자세로 옮긴 `Diver_<Kind>_*.anim`(회전 그대로, 뼈 위치는 새 기준 자세 + 노랑 움직임 차이).
- 1인칭 손과 작살총: 노랑 메시 그대로, 노랑 칠만 바꾼 아틀라스 재질 `DiverHands_<Kind>_Cartoon`, `HarpoonGun_<Kind>_Cartoon`.
- 런타임: `AquariumDiverKinds.model`(""/"_Tracker"/"_Drone") + `DiverPrefab/HandsMaterial/GunMaterial/PaintGun`. 3인칭 잠수부(종류 바뀌면 다시 만듦), 로비 잠수부 줄, 1인칭 손·받는 손·총, 미리 굽기(손가락) 모두 종류별.
- `AquariumFingers`: 손가락 찾는 절단을 .60에서 못 찾으면 .66/.72/.78로 늘려 봄(새 장갑은 손바닥이 길어서). 노랑은 그대로 .60.
- 노랑 잠수부·기존 자산은 손대지 않음.
