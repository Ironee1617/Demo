게임을 시작하면 서로 최소 16m 떨어진 환수구 네 개가 생성됩니다.
맵의 네 구역마다 하나씩, 바위·산호·해초·조약돌·통행로를 피한 후보에서 선택합니다.
새 라운드와 새 연습 게임/방 모두 위치를 다시 뽑습니다. 같은 게임 중에는 위치가 유지됩니다.
실제 위치와 회전은 호스트 스냅샷에 포함되어 클라이언트에 전달됩니다.
환수구용 난수를 분리했으므로 기존 물고기의 난수/이동 동작은 바뀌지 않습니다.

현재 범위
모델링과 라운드 배치만 구현했습니다. 나사 돌리기, 뚜껑 열기, 촉수 조작, 파이프 진입은 아직 없습니다.
2026-10-28 수정: 매 라운드 네 개 중 무작위 한 개는 열린 상태, 나머지 세 개는 닫힌 상태입니다.
열린 뚜껑은 테두리에 기대며 여섯 나사도 분리된 채 덮개를 따라 이동합니다. 열린 상태도 호스트 스냅샷으로 공유합니다.
배치는 시각 표현만 적용한 상태이며 뚜껑/나사 조작과 파이프 진입 상호작용은 아직 없습니다.
모래 렌더링은 환수구 입구에 맞춰 잘리며, 게임의 기존 바닥 충돌은 유지합니다.
추후 출입 상호작용을 구현할 때 바닥 충돌 예외와 파이프 내부 이동도 함께 연결해야 합니다.

편집/검증
Blender에서 원본 파일을 편집할 수 있습니다. build_drain.py를 Blender의 background Python으로
실행하면 같은 폴더의 export에 Blender와 FBX 및 재질 슬롯 JSON이 생성됩니다.
FBX와 material-slots.json을 Drains/Art에 넣고 Unity 메뉴
Aquarium > Return drains > Import model and bake sites를 실행합니다.
산호/해초/지형 배치를 바꾸면 Re-bake clear floor sites 메뉴로 후보를 다시 계산한 뒤 Validate를 실행하세요.
미리보기 이미지: ArtSources/ReturnDrains/Preview/

검증 결과
- Unity 스크립트/셰이더 컴파일 오류 없음.
- 무작위 시드 1,000개: 매번 4개, 최소 16m 이격, 지형 조건 통과.
- 뚜껑 1개 + 독립 나사 6개, 실제 미터 단위와 파이프 방향 확인.
- 스냅샷 JSON 왕복 후 위치/회전 일치, 라운드 내 고정, 다음 라운드 재배치, 로비 정리 통과.
- 별도 환수구 시드가 물고기 초기 배치에 영향을 주지 않는 것 확인.
- Unity 실제 Play Mode에서 연습 게임 두 번: 4개/나사 총 24개, 새 배치 확인, 실행 오류 없음.
- 실제 실행 중 네 위치를 이미지로 검수. 파이프를 연 검수 이미지에서 모래로 입구가 막히지 않음 확인.
- Git diff 공백 검사 통과. 기존 Packages 변경은 보존했습니다.
