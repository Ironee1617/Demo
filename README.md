## 서약의 탑 · 2D 로그라이크 데모

**최신 개선판 실행:** Unity의 `Assets/Demos/Roguelike/20_Roguelike.unity`에서 Play. **100층**을 등반하며 5층마다 테마·보스가 바뀌고 증강 세 장 중 하나를 고릅니다. 신화 선택 없이 **출발할 때, 30층, 60층**에 10개 신화 50명 전체에서 동료를 한 명씩 영입하며, 같은 신화 동료 2·3명은 신화 시너지를 발동합니다. 5층마다 일반 출구 대신 **휴식(생명력 50% 회복)·상점(상인에게 가서 층 포인트로 한 번 거래)·엘리트(클리어 시 증강)** 문 3개 중 하나를 고릅니다. 보스 7종은 공통 기술과 테마 고유 기술을 번갈아 쓰고 체력 50% 아래에서 격노합니다. A/D 이동 · Space 점프(짧게 누르면 낮은 점프) · J/클릭 공격(3타째 마무리 일격) · Shift 회피(공중에서 높이 유지) · 회피 중·직후 공격으로 돌진 베기 · E 출구·상인 거래 · Tab 영웅·동료 능력 확인. 기존 빌드 `Build/TowerEdenBalanced/`는 이전 25층 규칙입니다. PROTOTYPE 04는 주인공 기준 전위·중위·후위 진형, 82% 크기의 동료, 관절 애니메이션, 진동 없는 카메라를 적용했습니다. 경로·위험 구역 표시 없이 피하는 탄막 3종, Ctrl 정밀 이동, 근접 공격으로도 잡을 수 있는 공중 적과 상단 세 단 발판을 지원합니다.

맵은 올림포스·아스가르드·단군신화·에덴·베다·파피루스·중국신화의 7개 신화 테마 중 무작위로 정합니다. 5개 층마다 직전 테마를 제외하고 다시 추첨하며, 테마마다 일반 몬스터 6종과 보스 1종을 사용합니다. 보스는 5·10·15·20·25층에 등장합니다. 층마다 오르막·내리막이 있는 지면과 기울어진 발판을 시드로 무작위 생성합니다. [테마·몬스터 목록](Docs/Roguelike-Themes.md)

## 물고기 술래잡기 데모 v0.1



2026-10-15자 `수족관_술래잡기_게임기획서_v0.1.pdf`를 참고해 2026-10-16에 다시 만든 데모입니다. **외계인 4명 + 잠수부 1명**, 역할별 3인칭/1인칭 수영, 위장·포식·60초 허기·질주, 동족 포식의 경직·변신 제한, 부활용 알, 잠수부의 작살·먹이·중립 탐지, 개인 순위를 구현했습니다.



**최신 실행:** `Build/Aquarium-controls-ui/AquariumDemo.exe` → 역할 선택 → **AI 연습 시작**. 공유할 때는 `Aquarium-controls-ui` 폴더 전체를 전달하세요. Unity에서는 `Assets/Demos/HideAndSeek/30_HideAndSeek.unity`를 열고 Play를 누릅니다.

W 바라보는 방향으로 전진 · 마우스 시점 · Shift 질주 · 외계인 왼쪽 Alt 천천히 / Q 위장 / E 포식 / R 산란 · 잠수부 클릭 작살 / F 먹이 / R 탐지 · ESC 메뉴.

위를 보며 W를 누르면 상승하고, 아래를 보며 W를 누르면 하강합니다. 정면을 보면 높이를 유지하며 전진합니다. 결과 자유시점에서도 같은 방식으로 이동합니다.

일반 물고기와 외계인의 기본 이동속도는 4m/s로 같습니다. 작살에 맞은 물고기와 위장한 외계인 시체는 작살과 함께 잠수부에게 회수됩니다. HUD는 아이콘·막대·숫자와 짧은 행동 키 표시를 사용하며, 자세한 조작은 메뉴의 **조작 · 규칙**에서 확인합니다.

개선판에는 부드러운 수영·중앙 시점, 변신 대상 한 마리의 윤곽선, 준비 시간 포식 금지, 10m 안에서 들리는 먹이 소리를 반영했습니다. 외계인 사망 후 2.5초 동안 시체를 보여주고 관전으로 전환합니다. 부활 알이 남으면 경기를 계속하며, 실제 종료 때는 사망 연출을 건너뛰고 죽은 개체를 숨긴 정지 장면을 자유시점으로 둘러봅니다.

인터넷은 **방 목록 → 참가** 또는 기존 **Relay 코드로 참가**를 지원합니다. 목록에는 **대기 중인 방만** 표시하며, 경기가 시작되면 숨기고 대기실 복귀 시 다시 표시합니다. 메뉴에서 **5초마다 자동 갱신**하며 **새로고침**도 사용할 수 있습니다. **온라인 방 만들기**에서 방 이름과 선택 비밀번호를 정합니다. 비밀번호는 빈칸이면 공개 방, 설정하면 **8–64자**이며 **코드로 참가할 때도 필요**합니다. 방에는 **관전자를 포함해 사람 최대 5명**이 접속할 수 있습니다. 경기는 사람 **2–5명**, 잠수부 정확히 1명으로 시작하며 부족한 외계인 자리는 AI가 채웁니다.

경기 중인 방은 **코드로 참가**할 수 있습니다. 중도 참가자는 먼저 **관전**하고, 다음 대기실에서 역할을 배정받아 플레이합니다. 방장이 접속을 유지하면 다른 사람의 입·퇴장과 재대결에도 **같은 방과 코드가 유지**되며, 방장이 나가거나 게임을 종료하면 방이 닫힙니다. **프로토콜 v6이므로 모두 같은 최신 빌드**를 사용하세요. 최종 빌드·실행 검증 범위는 배포 폴더의 `검증결과.txt`에 기록합니다.

## SourceTree로 함께 쓰기



이 폴더는 `main` 브랜치와 첫 커밋이 있는 Git 저장소입니다. 아직 원격 저장소는 연결하지 않았습니다.



1. 한 사람이 GitHub/Bitbucket 등에 **빈 비공개 저장소**를 만듭니다. 자동 README나 `.gitignore`는 추가하지 않습니다.

2. SourceTree에서 이 폴더를 **Add**로 열고, 저장소 설정에 원격 URL을 추가한 다음 `main`을 Push합니다.

3. 친구를 저장소에 초대합니다. 친구는 SourceTree에서 Clone 후 Unity Hub에 복제한 폴더를 추가합니다.

4. 한 장르를 함께 실험할 때는 `main`에서 `feature/survivors` 같은 브랜치를 만들어 작업하고, 검토 후 `main`에 병합합니다. 다른 장르는 `feature/roguelike`, `feature/hide-and-seek`처럼 분리할 수 있습니다.



씬이 폴더별로 분리되어 있으므로 서로 다른 씬을 맡아 작업하면 충돌이 줄어듭니다. 같은 씬을 동시에 수정할 때는 먼저 담당을 정하세요. `.meta` 파일은 에셋과 함께 반드시 커밋하고, `Library`, `Temp`, `Logs`, `UserSettings`는 커밋하지 않습니다.



큰 이미지·오디오·3D 파일이 늘어나면 두 사람 모두 Git LFS를 설치한 뒤, 어떤 파일 형식을 LFS로 추적할지 함께 정하세요. 이 시작 프로젝트에는 LFS를 강제로 설정하지 않았습니다.
