# 서약의 탑 데모 검증

Unity 6000.3.21f1 Windows64 Development 빌드입니다. 실행 파일은 `Build/TowerDemo/TowerDemo.exe`입니다.

층별 몬스터 수·능력치 상승과 3층 주기 보스를 적용한 PROTOTYPE 05입니다. 최종 실행 시각은 `build-report.json`, `playtest-report.json`, `art-report.json`, `combat-report.json`, `boss-report.json`에 기록됩니다.

## 빌드 범위와 안전성

- 원본 Unity 프로젝트를 동시에 열어 빌드하지 않았습니다.
- `.validation/TowerDemoProject`의 독립 파일 복사본에서 빌드했습니다. `Assets`, `Packages`에 junction, symlink, hard link를 만들지 않았습니다.
- `Assets/Demos/Roguelike`의 Scripts, Resources, Editor, `20_Roguelike.unity`와 각 `.meta`만 복사했습니다. 원본 RPGAsset 제작 파일은 포함하지 않았습니다.
- 빌드는 로그라이크 장면만 포함합니다. 빌드 도구는 변경한 PlayerSettings와 Always Included Shaders를 복구합니다.
- 최종 런타임·에디터 C# 파일과 폰트 `.meta`의 원본/복사본 해시 일치를 확인했습니다.
- 이미지·글꼴 원본 바이트와 모든 리소스 메타 GUID도 일치합니다. Unity가 복사본의 PNG `.meta`에 추가한 spriteID 및 피벗 소수 정규화는 정상적인 임포트 결과입니다.
- `source-snapshot-report.json`: 복사한 콘텐츠 255개 해시 불일치 0개, 장면·리소스 메타 GUID 불일치 0개, Git 추적 Assets 파일 799개 중 누락 0개입니다. 빌드 전에는 복사본의 메타 GUID가 올바른 32자리인지도 검사합니다.

## 검증 결과

- 모델 테스트 20개 통과. 매 층 보상, 정원 3명, 영입·스킬·특성 혼합, 같은 동료를 대상으로 한 카드 3개 허용, 해고 후 재영입, 독립 새로고침, 스킬 해금·3단계 강화, 특성 누적, 등급 경계 및 30,000회 추첨 분포를 검사했습니다.
- 난이도 순수 C# 테스트 6개 통과. 25층 몬스터 수의 단조 증가, 8개 보스 층, 능력치의 점진적 변화, 시작·마지막 층 수치, 보스 체력 및 입력 범위 제한을 검사했습니다.
- Unity 스크립트 컴파일, 리소스·글꼴·스프라이트·셰이더 검사, Windows 빌드 통과.
- `playtest-report.json`: `success: true`, 동작 검사 23개 통과, `errors: []`.
- 이동, 점프, 회피, 플레이어 공격으로 1층의 몬스터 4마리를 실제 처치했습니다.
- 이후 24개 층은 진행 규칙을 검사하기 위해 몬스터 목록을 비우는 명시적 자동 검증 fixture를 사용했습니다. 25층 전체를 정상 전투로 플레이한 검증은 아닙니다.
- 자동 검증 중에만 체력을 보충하고, 스킬 표적의 체력·위치·기본 공격 재사용 시간을 고정했습니다. 일반 플레이에는 이 보정이 적용되지 않습니다. 구체적인 체력 보충 횟수와 회복량은 JSON에 기록됩니다.
- 재현 가능한 시드 74에서 정상 카드 선택 API로 1층 세라 영입, 2층 세라 화염구 해금, 플레이어 화염구 해금, 기본 능력치 5개 획득, 21층 해고·새로 영입을 실행했습니다. 매 층 총 25번 증강을 선택했습니다.
- 플레이어의 실제 전투 값이 공격력 28→32.48, 최대 체력 160→184, 방어력 0→8, 이동 속도 6→6.72로 증가하고 공격 간격이 0.43초→약 0.371초로 줄어드는 것을 첫 해당 특성 선택 시 확인했습니다.
- 세라의 화염구는 선택 전 발동하지 않았고, 선택 후 실제 투사체와 연속 발동을 확인했습니다. 관측 발동 간격이 실제 재사용 시간보다 빠르지 않은지도 검사했습니다. 플레이어의 해금한 화염구도 실제 투사체를 생성했습니다.
- 플레이어의 공격 접촉과 동료의 실제 스킬 발사가 해당 캐릭터 프로필의 동작 접촉·발사 시점과 일치하는지 검사했습니다. 관측 시각과 허용 오차는 드라이버와 JSON에 기록됩니다.
- 해고 즉시 해당 동료의 스킬·쿨타임·발동 기록·투사체가 제거되고, 같은 동료를 다시 영입해도 이전 스킬이 남지 않는 것을 확인했습니다.
- 별도의 저수준 fixture에서 실제 `CastSkill` 실행 경로로 16개 스킬 효과를 모두 호출했습니다. 투사체·장판·연쇄·돌진의 피해, 빙결·독의 상태 적용, 치유·보호막·흡혈의 실제 효과를 검사했습니다. 이 16개 효과 검사는 스킬 상태를 직접 구성하며, 정상 카드 선택을 통한 해금·재사용 검증과 구분됩니다.
- 사망한 프레임에 마지막 몬스터가 죽어 층 클리어 회복으로 부활하는 경합을 근접 공격과 투사체 두 순서로 회귀 검사했습니다. 검증용 체력·몬스터·처치 수는 검사 후 복구합니다.
- 숨김 창에서도 카메라 RenderTexture와 실제 IMGUI 렌더링을 사용해 게임 화면 6개를 저장했습니다. 갤러리 6개도 실제 카메라로 렌더링했으며 빈 화면 검사와 직접 육안 검사를 수행했습니다.

## 원본 픽셀 아트·동작·효과

- 캐릭터를 새로 그리지 않았습니다. `source-art-report.json`에서 원본 캐릭터 PNG 195개, 원본 몬스터 PNG 5개, 원본 효과 PNG 9개, 원본 ZIP 내부 성 배경·장식·횃불 3개, 총 212개의 SHA256 바이트 일치를 검사했습니다. 새 보스도 원본 `mobIcon/Stage_0_Boss.png`를 그대로 사용합니다. ZIP은 읽기 전용으로 열고 추출하지 않았습니다.
- 원본 Skeleton의 weighted mesh와 대기·이동·공격·사망 클립 64개를 16명에게 적용했습니다. 원본 출처와 추출 과정은 `Docs/Roguelike-Art-Sources.md`, 효과는 `Docs/Roguelike-Effects.md`, 배경은 `Docs/Roguelike-Environment-Sources.md`에 기록되어 있습니다.

## 전투 규칙 추가 검증

`combat-report.json`은 기존 진행 검증과 분리한 명시적 fixture입니다. 검증용 동료 구성과 몬스터 체력·위치·공격 패턴을 고정하며, 일반 플레이에 이 보정을 적용하지 않습니다.

최종 실행에서 추가 전투 검사 24개가 통과했고 `success: true`, `errors: []`입니다. 여섯 화면에서 진형·공중 표적·조준 경고·벌어진 탄막·점프 회피를 확인했습니다. 공중 면역 판정 fixture는 높이가 아닌 직업 제한이 적용되는지 확인하려고 표적을 검이 닿는 낮은 높이에 둡니다.

- 실제 이동 입력으로 방향을 뒤집고 역할별 진형 위치가 유지되는지, 이동 중에도 동료가 따라오는지, 동료 그림만 0.82배인지 검사합니다.
- 공중 표적은 플레이어·전사에게 선택되지 않고 피해도 받지 않으며, 원거리 동료에게는 선택되고 피해를 받는지 검사합니다. 원거리 동료 없는 층 생성과 마지막 원거리 동료 해고 후 착지하여 진행이 막히지 않는지도 검사합니다.
- 실제 몬스터 예고·발사 경로로 3발 부채꼴, 4→6발 틈새 연사, 9→10발 안전 구간 방사 패턴을 검사합니다. 예고 시작 후 플레이어 위치를 바꿔도 조준이 갱신되지 않고 발사된 탄이 직선으로 움직이는지 확인합니다.
- 같은 탄에 정지 상태는 맞고 실제 점프 입력은 피하는지 비교합니다. 실제 회피 입력이 공격 동작을 취소하고 무적을 제공하는지, Ctrl 정밀 이동이 속도를 45%로 낮추고 피격 중심을 표시하는지 확인합니다.
- 플레이어의 자동 스킬을 발동 가능 상태로 만든 뒤에도 수동 회피 중에는 새 시전을 시작하지 않는지 검사합니다. 이 설정은 해당 fixture가 끝나면 제거합니다.
- 빠른 탄이 프레임 사이를 가로질러도 상대 이동을 포함한 충돌 검사로 명중·사망하는지, 피격 후 고정된 카메라가 흔들리지 않는지 검사합니다.

## 층별 난이도·보스 검증

`boss-report.json`은 추가 검사 25개가 모두 통과했고 `success: true`, `errors: []`입니다. 원거리 동료가 없는 고정 구성으로 25개 층을 실제 생성해 일반 적과 보스를 구분했습니다. 일반 적은 4마리에서 12마리로 늘고, 보스는 3·6·9·12·15·18·21·24층에 정확히 한 마리씩 추가됩니다. 이 구성에서 보스를 포함한 총 적 수는 다음 층에서도 줄지 않습니다. 원거리 동료가 있으면 2층부터 추가되는 공중 적 한 마리는 이 집계와 별도입니다.

일반 적의 실제 전투 경로를 호출하여 다음 값을 비교했습니다. 경고 시간은 그대로 유지하고 공격 사이 회복 시간을 줄입니다.

| 검사 값 | 1층 | 25층 |
| --- | ---: | ---: |
| 근접 피해 | 10 | 17.2 |
| 이동 속도 | 1.9 | 2.2648 |
| 탄 속도 | 4.6 | 5.152 |
| 탄 피해 | 9 | 15.48 |
| 공격 경고 | 1초 | 1초 |
| 공격 주기 | 3초 | 약 2.678초 |

- 모든 일반 적의 실제 최대 체력·런타임 배율을 층별 공식과 비교했습니다. 보스 체력은 3층 420에서 24층 1081.5로 증가하며, 보스는 지상 표적으로 모든 직업이 공격할 수 있습니다.
- 실제 보스 실행 경로로 왕관 연사 3회×5발, 쌍나선 8회 총 22발과 지속 안전 통로, 1.35초 경고 후 0.85초 도약·착지 피해와 0.35초 후 추가 지상 파동을 확인했습니다. 조준 고정·경고 중 피해 없음·발사 간격·원본 스프라이트의 서로 다른 공격 동작 3종도 검사했습니다.
- 일시정지가 보스 경고를 멈추고, 새 등반이 보스 상태·경고·투사체를 제거하는지 확인했습니다. 피격 중 카메라 흔들림이 없는지도 재검사했습니다.
- 별도 3층 실제 전투에서는 보스의 정상 체력 420과 플레이어 기본 능력치를 유지했습니다. 일반 적 4마리는 보스 사망 전 보상이 열리지 않는지 확인하려고 멀리 옮겨 잠시 기절시켰습니다. 이동·검 공격·점프·회피 입력으로 보스를 처치한 뒤 기절을 해제하고 같은 입력 경로로 일반 적도 모두 처치했습니다. 직접 피해 함수를 호출해 전투를 끝내지 않았습니다.
- 이 실제 전투 fixture에서만 플레이어 체력을 3회, 총 약 31.8 보충했습니다. 총 처치 5회, 모든 적이 사망한 뒤 층 클리어·증강 3칸이 정확히 한 번 생성되는 것을 확인했습니다. 8개 보스 층 전체의 난이도나 25층 전체를 정상 전투로 완료한 검증은 아닙니다.
