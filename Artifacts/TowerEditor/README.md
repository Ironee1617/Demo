## 동료 공격

- 15명 전원의 기본 공격 준비·접점/발사·실제 적 체력 감소를 확인했습니다. 직접 피해나 투사체를 주입해 성공을 대신하지 않습니다.
- 전위 전사는 공중 적을 때리지 못하고, 궁수·마법사·치유사 대표는 실제 기본 투사체로 피해를 줍니다.
- 세라의 화염구는 학습 전에는 발동하지 않았고, 학습 후 시전·발사·피해와 반복 주기를 확인했습니다. 설정 쿨타임 4.820초, 관측 시전 간격 약 4.822초였습니다.
- 기본공격 준비·스킬 시전·비행 중 투사체·지속 영역에서 해고 처리를 검사했습니다.
- 공격 준비 중 적이 뒤로 넘어간 경우를 검사했습니다. 수정 전 루크는 반대 방향 적에게 13 피해를 주었고, 수정 후 같은 상황에서 피해가 0입니다. 전방의 기본 공격 15종은 계속 명중합니다.

동료 사례는 매번 새 고정 시드 실행과 지정된 동료 구성을 사용합니다. 영웅 입력은 끄고 대상 체력을 100000으로 높이며 적의 공격을 중지합니다. 배운 스킬 사례는 기본 공격을 억제해 스킬 피해와 재사용 시간을 분리합니다. 무작위 영입 카드나 전체 난이도 균형을 이 검사로 대신하지 않습니다.

## 보스 탄막

왕관 연사·쌍나선·도약 강타의 예고, 잠금 조준, 발사 지연, 안전 구간, 충돌, 공격 동작, 일시정지·정리를 검사했습니다. 25개 층의 적 수·능력치와 8개 보스 층도 확인했습니다.

경고 중 플레이어 검격과 루크 기본 공격으로 실제 보스를 밀었습니다. 수정 전 왕관 경고선은 최대 0.494 단위 / 1.650도 어긋났습니다. 수정 후 왕관·쌍나선 각각 플레이어 밀림 0.350, 동료 밀림 0.220에서 경고선 위치·각도 오차가 보고서 정밀도 기준 모두 0.000이었습니다. 도약 강타의 착지 표식은 고정 위치를 유지합니다.

실제 입력 전투로 3층 보스와 부하를 합쳐 5마리를 처치하고 보상이 한 번만 열리는지 확인했습니다. 이 전투 fixture는 체력을 3번 보충하고 부하를 단계별로 활성화하므로 일반 플레이 완주나 난이도 균형을 검증한 결과는 아닙니다.

최초 CLI 시도에서는 평가 명령의 기본 5초 제한으로 시작 요청이 만료됐습니다. 실행 스크립트의 평가 제한을 60초, 외부 요청 제한을 90초로 명시한 뒤 전체 시나리오가 통과했습니다. 초기 전송 오류 로그는 로컬 검증 폴더에 보관하고 최종 검사 전에 콘솔을 초기화했습니다.

## Windows 실행 파일 교차 검사

`Tests/Build-TowerDemo.ps1`의 독립 복사본으로 23:02:40 KST에 Windows 데모를 갱신했습니다. 소스·메타 539개 파일의 원본/복사본 해시가 일치했습니다. 기존 Player용 초기화 경로에서도 일반 전투 24개와 보스 26개 판정이 통과했고 오류와 종료 코드는 모두 0이었습니다. 로그와 새 Player 캡처는 이 폴더의 `player-*`에 로컬 저장합니다.

기존 카메라 검사는 고정된 실제 시간 1.8초만 기다린 후 위치가 완전히 같아야 한다고 가정하여 Windows에서 실패했습니다. 자동 추적의 정착과 피격 효과를 분리하기 위해 동일한 Unity 프레임·시간 간격에서 실제 Update의 무피격 15회 경로와 피격 15회 경로를 비교하도록 fixture를 바꿨습니다. 카메라 공식을 테스트에 복사하거나 게임 카메라 동작을 변경하지 않았습니다. Editor와 Player 모두 경로 오차 0.000000, 실제 피격 피해 12.000을 확인했습니다.
