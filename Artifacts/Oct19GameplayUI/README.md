# 2026-10-19 이동·작살·HUD 검증

일반 물고기와 외계인의 기본 속도를 4m/s로 통일하고, 플레이와 결과 자유시점의 이동 입력을 W와 마우스로 제한했다. Shift 질주와 Alt 느린 이동은 유지한다. 작살에 맞은 일반 물고기·외계인 시체는 회수되는 작살 끝에 붙으며, 회수된 물고기는 잠수부를 밀지 않고 가라앉는다. 스태미나·허기는 아이콘·막대·숫자로 표시하고 긴 설명은 메뉴로 옮겼다.

| 검사 | 결과 |
| --- | --- |
| `Tests/Run-ModelTests.ps1` | 88개 통과, 실패 0 |
| Unity 6000.3.21f1 컴파일러 | 플레이어 소스 32개, 에디터 런타임 32개, 에디터 21개 컴파일 성공 |
| 실제 플레이어 작살 검사 | 적중·부착·회수·재장전 통과, 시체 약 4.88m 이동, 오류 0 |
| 두 역할의 실제 플레이어 수영 검사 | 위·아래 이동, 수평 유지, 정지 모두 통과, 오류 0 |
| HUD 화면 검사 | 두 역할, 1440×900과 1280×720에서 아이콘·패널 표시 확인 |

모델 회귀 검사는 종별·도주 시 속도 일치, 움직이는 잠수부에게 시체 회수, 회수 전후 잠수부 밀림 방지, 위장한 시체의 모습 유지, 회수 도중 부활 시 연결 해제를 포함한다. 화면 검사는 총구에 맞춰 조정된 최종 작살 끝과 시체의 위치가 일치하는지도 검사한다.

`harpoon-clean.json`, `swim-hider-clean.json`, `swim-seeker-clean.json`은 별도 캡처 코드 없이 실제 소스로 컴파일한 DLL의 실행 결과다. `*-hud.png`는 숨겨진 Windows 실행 창에서 동일한 `AquariumGame.OnGUI`를 호출하는 검증 전용 Repaint 보조 코드로 캡처했다. 이 보조 코드는 최종 실행 파일의 DLL에 포함하지 않았다.

최종 실행 경로는 `Build/Aquarium-controls-ui/AquariumDemo.exe`다. 기존 Mono 플레이어와 리소스를 독립 복사하고 현재 소스의 DLL을 컴파일해 적용했다. Unity 전체 빌드 파이프라인은 실행하지 않았다. 최종 DLL SHA256은 `4DA4CAD04D453F6CE7BC52535BF1444308C95D9EFB83A1FBB6865C751ED0CDC7`이다.

현재 열려 있는 Unity 에디터와 원본 배포 폴더는 유지했다. 별도 Unity 프로젝트나 소스 링크는 만들지 않았으며, 추적 중인 에셋과 메타 파일 삭제는 없다.
